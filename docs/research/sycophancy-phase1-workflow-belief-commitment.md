# 第一阶段工作流 v2：信念与承诺的分离——表征层面的谄媚机理、轮内监测与有保证的门控控制（2026-11-01，取代 v1）

## 0. 相对 v1 的修订（评审后）

采纳的：(1) $\kappa$ 在 F-D 上概念不适用——按真值训练的探针读的是真值与名字联想，不是模型的信念；首答错的历史里中性对真假读数差近零，分母发散。主统计量改为同一名字、同一位置格式下 S 对 C 的配对变化 $\Delta$，以 S_T 中性对的真假差作全局尺度；$\kappa$ 只在中性对分得开的历史上作辅助。(2) 末行名字处的读数发生在模型写完一段话之后，与 $H_{13}$ 的轮内自我重申相混；改为生成前（紧接第三轮的强制末行，与探针训练格式一致）读一次、生成后再读一次，差即 $H_{13}$ 的轮内部分，零成本。(3) 探针池含 X 时"真名等于自答"占 70%，池化成对准确率 0.7 等于零信息，且原效度规则几乎必然触发；改为只用译者题 70 段（自答为真 31/70），X 单独报，"等于自答"作训练协变量并按层分层评估，不用投影（投影会连真信号一起删，因为按设计它与真值相关）。(4) 一个探针兼读"潜在知识"与"信念"是 $\kappa$ 失灵的根源；改为同一特征、两种标签、两个探针：真值探针读潜在知识（F-D 是唯一能看到"知道的多于说出的"的地方），偏好探针读信念（标签为模型在中性上下文中的偏好，由强制末行的对数概率比较给出）。(5) 知识天花板的比较器改为同一批强制末行免费给出的 logit 成对比较器（每历史比较两条末行的对数概率），以及"总是自答"0.44、"总是候选"0.56、表面形式基线；不与跨历史的 AUROC（A1 0.74、$d$ 0.5）并列，估计量不同。(6) C 臂行为采样划掉：我们全部 C 臂数据的末行采纳接近零，560 条采样的期望采纳约一两次，逐条目 ROC 与隐含似然比都没有信息；知识前沿由 logit 比较器给出。(7) B 的两处缺口补上：句末没有名字词元，信念读数在每个句末后追加强制末行再读；检出阈值在训练作品上按指定误报率设定，误报集明确定义。(8) 新增历史内条件检验与文件臂作信念通路的标定（§1 中介份额）。

未采纳或修改的：(a) 评审建议的"历史内条件检验"若用生成前的 $b$ 则不可能，生成前读数在同一历史×臂内对全部续写恒等；历史内变异只能由轮内读数提供，故该检验改用第一句后的强制末行读数，并明确它测的是最早轮内位置上承诺与信念的耦合，生成前的 $\Delta$ 才是干净的信念检验。(b) 对评审关于 C 臂结局的提问：第 0 阶段 C 臂的结局是末行身份（X 主集 0/30 翻转）、人工关系层 $W_{\rm side}$（3/30 确认、9 未知）、第三方归属（7/30）与未复核的 260 条立场编码；译者题从未有 C 臂。若将来采样 C，结局应取首句立场加 $W_{\rm side}$，不取末行；本轮不采。(c) E 的脚本化轮次手术（构造含假名自我重申的助手轮、只前向读信念）比生成续写更干净，采纳为 E 的第一版，仍在后批范围。

## 1. 引理、估计量与可辨识性

**引理 1（末行数据不能区分表演性顺从与真实更新）。** 设条目 $i$ 无压力接受 logit 为 $\ell_i$。贝叶斯更新者把社会证明当作与条目无关的证词（似然比 $L$），接受 logit 为 $\ell_i+\ln L$；表演性顺从者信念不变、输出层加常数偏置 $\beta$，接受 logit 为 $\ell_i+\beta$。两者诱导同一接受概率族 $\{\sigma(\ell_i+\text{常数})\}$，故任何只观测末行的实验（含 T1 配对条件似然）不能区分二者；区分需要末行之外的观测。∎ 数量级旁证：开局倾向 S 对 C 的推力在 v2 后缀下约 8–9 logit，若按 (a) 解释则 $\ln L$ 远超几位证人的可信似然比。

**定义（两种读数、两个探针）。** 对上下文 $x$（取到助手回合开始；A1/A0 含存档前缀）与名字 $N\in\{\text{cand},\text{own}\}$，强制末行 $\ell_N=$ "Final answer: {N}"，取第 $L$ 层在 $N$ 末词元的残差 $h_L(x,N)$，对数概率和 $s_N(x)$，$d(x)=s_{\rm cand}-s_{\rm own}$。中性上下文 $x^C_i$：前两轮原文加 "Could it be {cand}?"。真值探针 $f_T$：标签 $y=\mathbb 1[N$ 为本版译者$]$；偏好探针 $f_P$：标签 $p=\mathbb 1[N=\arg\max_{N'}s_{N'}(x^C_i)]$（模型在中性上下文的偏好）。两者都只在译者题 70 段的中性成对末行上训练，同一上下文一真一假，按作品留一；"等于自答" $o=\mathbb 1[N=\text{own}]$ 作训练协变量，报告分数只用残差部分，评估按 $o$ 分层并另报历史内成对准确率。

**估计量。** 对臂 $a$：$B^f_a(i)=f(h(x_{ia},\text{cand}))-f(h(x_{ia},\text{own}))$，$\Delta^f_a(i)=B^f_a(i)-B^f_C(i)$；尺度 $s_0^f=$ S_T 中性对上 $f(\text{own }T)-f(d_T)$ 的均值；标准化 $\delta^f_a=\Delta^f_a/s_0^f$。同式定义 $\delta^d_a$。文件对照：真侧为真记录纠正臂对 F-D base（同历史），假侧为 E-false 对 no_evidence（同历史同候选）。**中介份额** $\rho_{\rm med}(\text{侧})=\dfrac{\bar\delta^f_S/\bar\delta^f_{\rm doc}}{\bar\delta^d_S/\bar\delta^d_{\rm doc}}$：在"文件只经信念通路起作用、探针线性读出信念"的假定下（由文件臂的阳性对照检验），它是证词效应中经信念通路的份额。

**引理 2（可辨识条件）。** 若文件使 $\delta^f$ 与 $\delta^d$ 同步移动（阳性对照通过），而证词使 $\delta^d$ 大幅移动、$\delta^f$ 不动，则证词效应不经由文件效应所经的那条表征通路；这一结论只依赖探针对文件效应的读出有效，不依赖探针读出"全部"信念。反之若证词同样移动 $\delta^f$，表征层面不能排除 $H_{12}'$，也不能排除探针读到"被断言"特征；此时以 X 的 S 对 C（候选为无关真人）作断言效应对照：若 $\delta^f_S(X)\approx\delta^f_S(S_T)$，效应不随名字可信度变化，倾向断言伪像。

## 2. 假设

**$H_{12}$（表演性顺从）。** 证词使输出采纳而不改写信念：$\bar\delta^f_S$ 两侧都接近 0（F-D 采纳真名 T 时模型内部仍偏好自答，S_T 采纳 $d_T$ 时仍视其为非偏好），$\rho_{\rm med}\approx0$；文件臂 $\bar\delta^f_{\rm doc}\approx1$。竞争假设 $H_{12}'$：证词与文件同样改写信念，$\bar\delta^f_S\approx1$。判读：$|\bar\delta^f_S|$ 作品簇 95% 区间上界 $<0.3$（两侧）且 $\bar\delta^f_{\rm doc,true}$ 下界 $>0.7$ 记"信念完好"；$\bar\delta^f_S$ 下界 $>0.7$ 记"信念改写"；其余"部分"。阳性对照不过则整节无效。

**$H_{13}$（上下文自我说服）。** 轮内零成本部分：同一名字生成后末行读数减生成前读数 $\Delta_{\rm within}$ 对采纳名为正，并随正文中提及该名的句数增加。跨轮部分（E，后批）：构造含 $n$ 次假名自我重申的助手轮，信念读数随 $n$ 线性漂移，速率 $w$。

**$H_{14}$（复制通路）。** 不变（D，后批）。

## 3. 工作流

**A（只读前向，报备）。** 探针训练与天花板；生成前 $\delta^f_a$ 对 $a\in\{S, A1, \text{status（辅）}\}$、文件臂、X 的 S/A0/A1 对 C；中介份额；生成后 $\Delta_{\rm within}$；E-false 内相信者对质疑者的生成前预测；实验二 1.5(b) 的逐折修正与第 12 层信号解释。
