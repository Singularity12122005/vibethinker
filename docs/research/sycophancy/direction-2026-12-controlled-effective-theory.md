# 复盘与下一步：从"谄媚控制"到"上下文更新系统的受控有效理论"

> 性质：第三方审读与方向建议，不是负责人裁定，不含登记项。依据：本目录全部文件，含 2026-11 补入的 14 份原始报告与 1 份复算数据。所有数字均可在 `sources/` 与主计划 v1.54 中核到；本文不新增任何实验数字。受测模型始终是冻结的 Qwen3-30B-A3B-Instruct-2507，非思考模式，温度 0.7。

## 0. 一句话结论

项目最可靠的资产不是任何一个"谄媚方向"，而是三件事：一个随处可用的受控操作（禁读上一轮开场）、同种子配对分支（同一前缀下直接测 do(a) 的后果）、以及外部可核验的结局。**把这三件事放进一个"受控系统辨识"的框架**，用大量自动生成、自动评分的多轮对话去辨识"上下文更新系统"的状态、输入算子与干预算子，再把隐藏态当作状态的廉价传感器，才是通用的、可扩展的做法。RET 提供了其中的两个关键技术动作：自监督的闭合判据，与"宏观态先于标签"的研究顺序；但 RET 只研究自治系统，而我们的对象是带输入的受控系统。

### 1.2 失败的六个结构性原因

这六条是跨路线的，比"某个读数不灵"更重要。

1. **标签绑定的研究节奏。** 每个实验都依赖人工盲判正文断言，于是只有 9 部作品、28 + 5 道题、7 个题簇。样本小，区间宽，每次事实层效应没迁移，解释就换一个（角色错配→辩护竞争→修饰变量未识别）。被换的不是读数而是调节变量，而调节变量从未被单独操控。
2. **饱和的设计点。** M1 124/124、E-C 124/124、留出末行 8/242：基线接近 0 或 1 的材料对任何 δ 都不可见。命题 7 已把它写成定理，但材料构造仍反复落到饱和点。
3. **混杂的换域。** 书目与程序之间同时改变了事实可推导性、被遮跨度的话题相关性、任务关系与证据强度。再换域、再学状态，仍是"效应变了，不知为何"。
4. **常数平移使"择时"无价值。** A1 与路径遮断在对数几率上都近似常数平移（−4.5 与 −3.2 在动作层；A1 为 5–7）。固定 δ 下逐历史收益 σ(u+δ)−σ(u) 只随基线 u 变化、符号永不翻转，于是零成本下"始终干预"就是最优，择臂收益必然接近零（书目 3–7/248、程序 6–15/220）。+11.24 的成功与事实层择臂的失败是同一个现象的两面：有成本时幅度才重要，幅度由基线决定，基线就是入口读数。
5. **操作与待检命题错位。** 修复三例里，告警反驳的是"我的修法已奏效"，被遮断的却是"问题定位"；账本试点里模型能写假设却写不出返回不同就导向不同动作的检查。控制器的动作集缺少真正能获取信息的动作。
6. **仪器先于阳性对照。** internal1、internal3_A 在没有证明"量的是什么"之前就被用于预测。后期纪律（预登记、撤回记录、阳性对照）已经纠正，但早期沉没成本很大。

### 1.3 已经成立的规律

1. **阈值律。** 提示语与路径遮断是近似常数的对数几率平移，不改分辨力；只有窗口内可核验证据改分辨力。（Phase 0 H1；命题 7；Bigelow 等的信念动力学）
2. **开场即承诺，且承诺早于内容。** 模型回读自己上一轮的开场；作用在新回答开头实现（T1 32 对 T2 79）；前缀包效应 +0.250 对前缀期计算 −0.032。
3. **动作层跨域可预测。** 一次带遮断的前缀前向给出的首词概率差，一比一预测认可动作的消失比例（开发斜率 0.998、留出 1.042；相关 0.868、0.818），首词与人工标签零错配。这是一个已经冻结、无需按任务重训的跨域状态读数。
4. **证据主导事实更新。** 真记录在窗口内时两侧到天花板；无记录时遮断堵住部分真更新（M0 的 19 条损失中 17 条来自一部作品）；语义域附记录改对 6/9 对仅主张 1/9。
5. **承诺与信念可分离。** 51 对开场改变中 50 对两臂皆对；语义域社会证明下 6 条采纳中 5 条没有接受开场；书目 180 条操作后续写无一承认答错而错署 51 条。
6. **事实层效应有未识别的调节变量。** 书目 δ_事实 −1.10（假名）与 −1.82（真名）同号同量，程序 −0.29、+0.23 近零。候选调节变量：事实可推导性、被遮跨度与当前事实的话题相关性、任务关系、证据强度与适用性。

## 2. 第二步：从 RET 与 Ferrando 发展可以工作的思路

### 2.1 RET 到底做了什么（按 2605.09294v3 原文核对）

- **微观态** x_t = h^{(ℓ_mid)}_{0:t}：某一中间层上到当前词元为止的隐藏态前缀。时间是词元位置，不是对话轮。
- **宏观态** z_t = f_θ(x_t) ∈ R^128：单层因果 Transformer 加线性层与 LayerNorm。
- **目标**：一步预测的 L1 损失 ‖T_φ(f_θ(x_t)) − f_θ̄(x_{t+1})‖₁，T_φ 为两层残差 MLP，目标编码器为 EMA（m = 0.996），BYOL 式，无解码器，无额外防塌缩项。有监督变体加一个 MSE 头预测轮级谄媚标签（λ = 1），训练后丢弃。
- **闭合**：I(z_{t+1}; z_t, x_t) ≈ I(z_{t+1}; z_t)。在确定性（温度零）设定下退化为 H(z_{t+1} | z_t) ≈ 0。用留出一步自预测 R² 检验：RET 0.908–0.979，匹配基线 0.574–0.786。只有一步，无多步滚动；随机解码未测。
- **行为预测**：SYCON-Bench 扩到约 14,000 样本；读回答前 5%–10% 的宏观态；有监督 RET 最佳，无监督"高于随机但较弱"；数字只在图中。附录 J.4：两模型在二选一中知道正确答案 98.3% 与 98.7%，首轮即让步者仍 95.6% 与 97.1% 知道。
- **引导**：对 h_t^{(ℓ_mid)} 做短梯度上升步使宏观态靠近目标簇中心（s = 0.5，K = 3），排斥子按邻域门控；33 个提示中 30 个出现目标行为标记，SAE 对照 20/33。
- **转移算子 T_φ 只接收 z_t，没有输入项、没有控制项**。一个场景一个编码器，跨任务共享未测。

### 2.2 从 RET 拿什么，以及一处根本差别

拿来的三件事：(1) **状态先于标签**：用自监督闭合选择粗粒化，标签只用来验证读出。RET 能有 14,000 条样本，正是因为训练不需要人工标签。(2) **操作性心理状态**：状态的含义由它能预测什么定义，不先命名为"信念"或"熟悉度"。internal1 与 internal3_A 的失败，本质上是先命名、后验证。(3) **把干预写成状态空间里的几何操作**：吸引子与排斥子。

根本差别：RET 的对象是一次回答内部的**自治**轨迹。我们的对象是多轮对话：用户消息 u 与干预 a 是外生输入，模型自己写出的回答又作为输出反馈回输入。这是一个**受控的、带输出反馈的系统**。RET 的闭合判据对它不够：提案命题 1 已证明原生闭合不蕴含决策充分。需要的是受控闭合：I(z_{k+1}; c_k | z_k, u_k, a_k, o_k) ≈ 0，其中 o_k 是本轮回答的廉价摘要。

方法论上还有一处差别更要紧：我们每一步都卡在 7 个题簇、9 部作品，因为结局靠人工盲判。**可扩展的前提是把结局自动化**。首词事件已证与人工认可零错配；末行有解析器；外部甲骨文有执行、目录、计算。正文断言的人工标签只留给验证子集。

### 2.3 核心转换：把问题写成"上下文更新系统"的受控辨识

系统：冻结模型 M。第 k 轮上下文 c_k；用户输入 u_k ∈ 𝒰（带参数的消息类型：压力 P、证据 E、中性 N、复问 Q）；干预 a_k ∈ 𝒜（原生；禁读上一轮助手回答的首句，这是任务无关的通用定义；以后可加激活编辑）；回答 y_k ~ M(· | c_k, u_k, a_k)；观测 o_k =（首词事件，末行答案类）；c_{k+1} = c_k ⊕ u_k ⊕ y_k。结局在每轮相对固定的 (A, B) 编码：维持 A、采纳 B、其他、无结论；认可与否单列。

三个研究问题的系统论版本：

- **状态表示**：是否存在低维 z_k = φ(c_k)，使 P(o_k | c_k, u_k, a_k) = P(o_k | z_k, u_k, a_k)，且 z_{k+1} = U(z_k, u_k, a_k, o_k)。
- **演化预测**：辨识算子 U 与读出 g。检验消息算子是否对易（顺序效应）、干预是否为平移（阈值律）、证据算子是否跨族相同（共享更新规则）。
- **反馈控制**：用 (z, U, g) 选择 a_k 与要索取的信息，在受控闭环中相对重读完整历史的策略计算遗憾与成本。冻结模型本身就是可以任意滚动的仿真器，闭环评价不需要真实用户。

"通用"由此变成一个阶梯，每级单独签发：同一方法（同目标、同架构）→ 同一行为状态（测试电池）→ 同一算子（冻结 U、g）→ 同一编码器（冻结 φ）→ 同一控制规则。现有证据已经支持动作层的第二、三级：t₀ 读数是一个冻结的跨域状态，它的干预算子是常数平移。

### 2.4 三个可以直接开工的设计

**设计 A：行为锚定的预测状态（PSR 测试电池）。** 在任一前缀 h 上，用一组固定的反事实续写"测试"定义状态：T₀ 直接中性追问；T_P 先加一条标准压力再追问；T_E 先加一条已核实记录再追问；T_E′ 先加一条真实但不适用的记录再追问；可选 T_a 在禁读上一轮首句的条件下追问。每个测试的结局为（维持 A，采纳 B，其他）的概率；认可概率从 T_P 回答的首词读出，不从中性追问读（语义域中性复查下认可 55/55，是天花板）。z(h) 是这些预测的向量，约 12 维，再按秩选择压缩。它的定义在书目、程序、算术、文档题上逐字相同；它对电池内动作的决策充分性由构造保证；它把"证据敏感度"作为坐标显式纳入。这正是负责人方案准备在失败后才加的"第四坐标"；Ferrando 的做法是从一开始就用独立行为定义概念，再看它在表现最差的类别上是否仍成立。三种估计器对应负责人表里的三种方法：实际分支（训练与评价）、隐藏态回归 ẑ = g_θ(h^{(ℓ)}(t₀))（部署）、递归更新 ẑ_{k+1} = U(ẑ_k, u_k, a_k, o_k)（最便宜）。

**设计 B：线性算子辨识与对易子。** 先不训练 U_θ，先拟合最简单的受控线性模型：在对数几率坐标上 z_{k+1} = A_m z_k + b_m（m 为消息类型与参数），干预为读出偏移 δ_a(z) = δ₀ + δ₁ᵀz。七格设计加上跨题目的 z₀ 变异足以辨识 A_P、A_E、b_P、b_E。顺序效应就是对易子 [A_P, A_E] 与相应仿射项；Bigelow 等的加性模型对应 A = I、对易子为零。这把负责人方案里的判别量 C 推广为可逐坐标解释的对象：哪些坐标是顺序敏感的。PEP／EPP 成为算子模型的样本外检验。阈值律对应 δ₁ ≈ 0（动作层）；事实层的调节变量就是 δ₁ 载荷最大的坐标。这是对"修饰变量未识别"的系统化回答，不再靠叙事。

**设计 C：受控闭合训练的隐藏态编码器（c-RET）。** 在设计 A 的语料上训练 φ: h^{(ℓ)}(t₀) → z。损失 = 受控一步闭合（输入 (z_k, e(u_k), a_k, o_k)，预测 EMA 目标 z_{k+1}）+ 自动结局读出。与 RET 的差别只在转移网络多了输入项与观测项，以及读出用自动标签。评价：按动作分别报告闭合 R²，遮断臂下的闭合退化就是命题 1 反例的检测器；留出族上冻结 φ 的读出误差；与设计 A 的行为状态做典型相关，看隐藏态是否多出行为电池看不到的坐标。最值得找的一个是"知道真值"：RET 附录 J.4 显示模型 98% 知道正确答案而仍让步，这个坐标在 z₀ 的行为里被 argmax 截断，正是 Phase 0 说的 θ 不可从输出恢复。

**热身（零新生成）：在现有回答上复现 RET。** 对已存档的 3,768 + 768 + 504 条自由回答做带钩子的前向，用 RET 原目标训练回答内宏观态，读 5%–10% 处预测末行采纳；对照 internal3_B 的 d_t 监测器（召回 0.995，F-D 良性报警 0.94）。预测：RET 宏观态同样对良性采纳报警，因为它学的是"要让步"，不是"该不该让步"。这一步成本极低，能直接回答"RET 在温度 0.7 的自由生成上是否闭合"，并给论文一个与 RET 的硬对接。

### 2.5 为什么这不是又一个"先找会动的量"

(1) 状态的定义是预测未来受控结局，不是某个命名概念，阳性对照内置于目标。(2) 模型族是预登记的阶梯 L0–L4，所有方法预测同一结局、同一损失，赢家由留出决定。(3) 材料由甲骨文自动评分，题目数由生成预算而非标注预算决定。(4) 干预作为已知算子进入同一语料，控制问题由同一数据回答。(5) 调节变量通过算子载荷识别。

## 3. 第三步：实验设计

### 3.1 语料：受控激励设计

- **任务族**（每族 ≥ 150 题，首答正确与错误两侧都要，按零压力普查选中等难度 θ 0.25–0.75）：F1 记忆事实（Wikidata 型真值；不可推导，是书目的可扩展替身）；F2 程序语义（执行甲骨文，已有 64 留出题与答案匹配构造法）；F3 算术与日期（确定计算）；F4 文档内查找（答案在题面文档中，可由上下文推导）；F5 书目（现有 9 部作品，只作最终确认，不参与拟合）。F1 与 F4 把"可推导性"这个候选调节变量显式拉开。
- **输入字母表**：P 三档（温和复查、社会证明、坚持加权威）；E 五档（已核实真记录、真实但不适用的记录、伪造记录、纯逻辑论证、仅状态记录）；N；Q。每条消息模板化加措辞变体。同一题的 B 与 E 文案只生成一次、跨分支复用。
- **序列**：长度 1–4 的随机序列，保证七格（PE、EP、PN、NP、EN、NE、NN）与 PEP／EPP 的覆盖，并含多次 P 的"锁定"序列。每条序列末尾逐字相同的中性追问。
- **开环与闭环两个子语料**：中间助手轮固定为"已读，请继续"（开环，测用户信息的更新规律），或自由生成（闭环，含模型对自己开场的回读）。两者之差就是自反馈增益。书目机制预测它在 F1、F5 大，在 F2、F3、F4 小。这是把"修饰变量"变成一个可逐族测量的增益。
- **干预**：闭环子语料中随机四分之一的轮次做同种子配对分支：原生对禁读上一轮助手首句。
- **记录**：每个前缀在 t₀ 的若干层隐藏态与首词分布；每个回答的首词事件、末行解析、甲骨文判定。正文断言只对验证子集人工盲判。
- **规模与成本**：约 600 题 × 16 条序列 ≈ 10k 对话，生成约 6M 词元；电池探测约 12M 词元；干预分支约 0.6M 词元。相当于现有总生成量的十倍，在一张 A100 上以天计，不以月计。

### 3.2 模型阶梯（预登记，同一损失）

| 级 | 模型 | 它回答什么 |
|---|---|---|
| L0 | 无记忆：结局只依赖题目基线与最后一条实质消息 | 近因是否已足够 |
| L1 | 加性对数几率：每种消息按位置有独立作用，允许衰减与饱和 | Bigelow 型可加律是否成立 |
| L2 | 线性受控状态（设计 B），秩由折内选择 | 顺序效应住在哪些坐标 |
| L3 | 非线性学得状态：设计 C 的 c-RET，或从设计 A 的 z 学 U_θ | 隐藏态多出了什么 |
| L4 | 重读完整历史：实际分支 | 上限 |

统一指标：留出题上各（序列，动作）下结局概率的对数损失与 Brier，两侧分报；逐题顺序差的预测；多步滚动误差（递归不回填）；成本敏感决策价值 G、ΔG（提案命题 2）；跨族冻结后的同一指标。

### 3.3 预登记的假设与证伪

| 假设 | 内容 | 证伪 |
|---|---|---|
| H-A 对易性 | 开环子语料中 [A_P, A_E] ≈ 0，顺序只经最近消息与饱和起作用；闭环中对易子非零且载荷在承诺坐标 | 开环中对易子显著，且 PEP／EPP 被 L2 预测而 L1 不能 |
| H-B 干预为平移 | δ₁ 在认可坐标 ≈ 0；在事实坐标显著，主要载荷在证据与可推导性坐标 | 动作层 δ₁ 显著依赖 z |
| H-C 迁移阶梯 | L2 的算子冻结后在留出族上不劣于族内重拟合超过预定容差；L3 的 φ 冻结后至多需要一个线性重对齐 | 冻结算子在留出族误差回到 L0 水平 |
| H-D 控制 | 只用 ẑ 的成本阈值策略在闭环滚动中取得重读策略增益的一半以上，计算成本低一个数量级，真纠正侧不劣于原生 | 增益不足一半，或真纠正侧受损 |

### 3.4 判决表

| 结果 | 结论 |
|---|---|
| L1 在全部族上与 L2、L3 等效 | 停止状态学习。"上下文压力与证据在对数几率上可加、顺序无关"本身是一条一般定律，与 Bigelow 等对接 |
| L2 优于 L1 且对易子集中于承诺坐标，开环为零 | 记忆来自模型自己写出的承诺，不来自用户消息的累积。控制对象就是承诺的写出，与书目机制一致 |
| L2 冻结可迁移、L3 不可 | 行为 PSR 是通用状态，隐藏态编码器是族内传感器 |
| L3 冻结可迁移并多出"知道真值"坐标 | 最强主张：同一隐藏态编码器在多族上给出决策充分的受控状态 |
| 开环与闭环都无顺序效应、无记忆 | 轮级动力学是平凡的。转回回答内部动力学（RET 本体）或更长对话 |

### 3.5 对负责人参考方案的具体修改

1. **保留**：七格、PEP／EPP、固定中间轮、三方法竞争、预选迁移方向、概率平方误差、判决表。
2. **不要手定三个坐标**：用电池定义候选坐标，秩由数据选；隐藏态编码器作第二层状态。三个坐标是 L2 的一个特例，不是起点。
3. **开环与闭环都做**：模型回读自己开场是已证机制，开环把它切掉。两者之差本身是要测的量。
4. **证据分档**：用真记录会复现 480 的零。非饱和点在真实但不适用、仅状态、纯论证这几档。
5. **材料靠甲骨文扩到 150 题/族**，书目退为确认族。标注预算不再决定题目数。
6. **先拟合线性算子再训练 U_θ**：对易子可解释，且 100 题即可辨识；U_θ 是 L2 失败后的备选。
7. **把禁读干预放进同一语料**：控制问题与演化问题共用数据，不另起炉灶。
8. **认可坐标从压力测试的首词读**，不从中性追问读。

### 3.6 不做与止损

- 不再在旧程序题上调首词阈值；不在 7 题簇上做新的事实层主张；不先训练 128 维状态再问它是什么；不以单侧结局报告任何控制收益；不把"交接完成"写成主张成立。
- 第一篇论文按已定的 A/B/C 结构收口（书目机制；动作层跨域与留出确认；事实控制的边界与控制器阴性结果）。本文是第二篇的起点，不改第一篇的判词。

## 4. 执行顺序与预算

| 周 | 内容 | 产出 |
|---|---|---|
| 0–1 | 热身：在存档回答上复现 RET，对照 d_t 监测器 | RET 在随机解码上的闭合 R²；良性报警率 |
| 1–3 | 语料生成器：三个自动甲骨文族、消息模板、解析器、开环与闭环、干预分支接口；预登记 3.2–3.4 | 可运行的生成管线；500 条对话试点 |
| 3–4 | 生成 10k 对话、电池探测、隐藏态与首词分布 | 语料与自动标签 |
| 5–6 | L0–L4 拟合与跨族评价；对易子与干预载荷 | H-A、H-B、H-C 的判决 |
| 7–8 | 闭环控制：成本阈值策略对重读策略 | H-D 的判决 |
| 之后 | 书目 F5 确认；验证子集人工盲判 | 第二篇论文主结果 |

最大的工程投入是第 1–3 周的生成器。它一旦存在，任何新任务族只需提供题目、候选生成器与甲骨文，整套状态、演化与控制评价自动运行。这才是"不为每个任务发明一套读数"的实际含义。
