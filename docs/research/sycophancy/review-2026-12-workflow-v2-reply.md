## 0. 结论

认同把第二篇主线定为"多轮谄媚过程的受控辨识"，认同保留七格、行为测试、跨题预测，认同先做小规模行为辨识再决定是否训练隐藏状态模型。负责人指出的两处推理错误成立，本文给出更正后的表述。在此基础上有七处加强，目的只有一个：让第一笔生成预算同时回答"有没有记忆"与"记忆的载体是什么"，并让零结果也成为可发表的正结果。

## 1. 完全认同的部分

1. 六条"定律"降级为"新实验必须击败的简单模型"与"已测体裁内成立的描述"。尤其是：常数平移只作为零模型；"开场即承诺"改为"一段有因果作用的早期生成窗口"；"承诺与信念可分离"改为"开场认可与最终事实回答可分离"，证据是 51 对中 50 对两臂皆对。
2. 七格最先识别的是顺序差，顺序差不等于机制；交互量 I_PE、I_EP 才是检验"前一条消息是否改变后一条消息作用"的对象，两者分别报告，在题目层建模后汇总。
3. 状态检验分三个时点：消息到达前、消息已到回答前、回答之后。真实末行只在第三时点进入更新器；依赖干预臂的读数要计成本。
4. 固定中间回答与自由回答之差不叫"自反馈增益"，它是"允许模型写出并带入完整中间回答"的总影响；定位到"回读自己的首句"要靠同一份已生成中间回答上的同前缀遮断配对，且只在出现关键交互的条件上做。
5. 控制阶段必须有真实可选动作（付费索证或直接作答），用户侧规则要写明；完整历史重读称强比较器，不称最优。
6. 执行顺序：先一个任务族的七格事实交互，再固定对自由加遮断，再小型测试组拟合最简状态模型并冻结迁移；RET 复现作并行低优先级。
7. 主问题的措辞比"一般有效理论"窄而更忠实。

## 2. 两处更正

### 2.1 常数平移推不出事实层择臂无价值

原文第 1.2 节第 4 条把"动作目标上 +11.24 的成功"与"事实目标上选择器未胜"归结为同一个机制。这一步缺了从开场动作到事实损失的推导，负责人的批评成立。更正如下。

设遮断使"采纳候选"的对数几率平移固定 δ < 0，则逐历史的采纳概率变化 Δ(h) = σ(u_h + δ) − σ(u_h) ≤ 0 恒成立，择臂对"采纳"事件确实无价值。但事实收益是
b(h) = −Δ(h) · s(h)，s(h) = +1 当候选为假，−1 当候选为真。
b 的符号由真值决定。择臂价值 E[(E[b | Z])₊] − (E b)₊ 在真值可由 Z 部分预测时严格为正。本项目的选择器之所以为零，不是因为平移，而是因为它只用首句特征，而首句特征携带承诺、不携带真值；且评价都在真值按侧固定的材料内进行。正确的结论是：**事实层择臂的价值等于决策前对真值或证据有效性的预测价值。** 已有数据里最简单的真值代理是"当前消息是否含可核验记录"：M1 两臂 124/124，M0 120→101。所以一个只看证据类别的规则（无记录才遮断）已经是非平凡的事实层策略，它的代价集中在"用户没给记录但恰好对"的历史上。第二篇要补的正是这一步：在回答前，哪些可观测量能预测当前候选为真或当前证据有效。

### 2.2 顺序差不是交互，七格不保证算子可辨识

负责人的例子成立：单状态衰减模型 z_{k+1} = ρ z_k + b_m 给出 z_PE − z_EP = (1−ρ)(b_E − b_P)，有顺序差而无记忆。更一般地，任何线性时不变系统配线性读出都没有交互：s_XY = c A² z₀ + c A b_X + c b_Y 对 X、Y 可加，故
I_PE = s_PE − s_PN − s_NE + s_NN = 0。
要出现非零交互，需要消息依赖的转移（双线性 z' = A_m z + b_m）或非线性读出。在双线性模型下
I_PE = c (A_E − A_N) [ (A_P − A_N) z₀ + (b_P − b_N) ]，
即"证据算子与中性算子的差，作用在压力造成的状态位移上"。这正是"前一条压力改变后一条证据的作用"的代数形式。于是：

- 原文第 3.4 节"加性模型胜出即顺序无关"撤回，改为"加性模型胜出即无交互，顺序差由位置权重解释"。
- 原文"对易子"不再作主要统计量。s_PE − s_EP 混合了位置权重项与交互项；主要统计量改为 I_PE 与 I_EP，各自报告，在题目层用对数几率尺度建模后汇总，概率尺度作次级。
- 原文"七格加跨题变异足以辨识完整算子"删除。可辨识性改为可检查项：各消息类型的输入状态在题目间是否张成足够多方向，用设计矩阵的秩与条件数报告；最终认可与末行两个可见量下多个内部算子可以等价，所以算子模型的地位是"用未参与拟合的三步序列检验其预测"，不是"由七格辨识"。
- 最大载荷只提出调节变量候选，不单独识别它。

## 3. 七处加强

### 3.1 三个开环程度，而不是两个

在"固定填充轮"与"自由回答"之外，加一个更干净的开环条件：把两条用户消息串接在同一条消息里（P 后接 E，或 E 后接 P），中间没有任何助手轮。三个条件按回答间的"生成介入"递增：串接（只有阅读顺序）→ 固定填充轮（有轮边界，无自写内容）→ 自由回答（有自写内容）。交互量沿这三级的增长直接定位载体：若串接已有交互，记忆来自上下文阅读本身；若只在自由条件出现，载体是模型自己写出的内容，再用同前缀遮断旧首句分出"回读首句"的份额。三个条件共用题目、候选与证据文案，串接条件几乎不增加生成量。

### 3.2 第三步加反向压力，把"承诺强度"变成可观测量

PEP／EPP 的第三条消息若仍是同向压力，测的是累积；加一个反向压力 P⁻（用户改回支持首答 A，或提出第三候选 C），测的是已形成更新的稳定性。先给证据再施压后，正确更新能否顶住后来的反向压力；先施压再给证据后，是否更容易被反向压力推回。这把 Phase 0 的"锁定"假设（辩护轮数越多越难翻转）变成七格的自然延伸，也给状态一个必须包含的坐标：翻回所需的压力强度。三步序列仍不参与拟合。

### 3.3 证据三档，并检查不适用性是否可检测

证据至少三档：适用的真记录、真实但不适用的记录（版本或输入不匹配）、伪造记录。前两档区分"证据有效性"与"证据文体"，第三档区分"文体"与"被核实"。书目 E2 中不适用的旧版记录被接受 32/32，说明文体可以压过有效性；Phase 0 中伪造记录无前缀 5/10 相信、加 A1 后 0/10。每档都要有一个零压力检查：中性设定下直接问模型该记录是否适用于当前命题。若模型根本检测不到不匹配，接受它就不是分辨力问题，而是信息问题，须分开报告。

### 3.4 充分性审计：一个与任务无关的通用方法

负责人第四节的反例检验可以推广为一个程序，它是对"预测方法太 ad hoc"的直接回答。

- 取当前摘要 σ(h)，候选坐标为（首词类别，末行类别，已见证据类别，已受压力次数）。
- 固定一条下一步输入 u*（例如标准压力），对摘要相同的历史集合 {h : σ(h) = s} 测结局 y。
- 用同一历史独立重复的交叉乘积估计格内历史间的条件均值方差：E[(y_r − ȳ_s)(y_{r'} − ȳ_s)]，r ≠ r'。这是提案命题 5 的估计量，不需要任何新标签。
- 方差为零：σ 在该格对 u* 充分。方差大于零：摘要丢了控制相关信息。随后在重复 1 上找能解释残差的可自动提取特征（正文断言、辩护轮数、证据适用性、t₀ 读数），在重复 2 上验证。
- 对三个时点分别审计。第三时点的审计回答"更新器需要本轮回答的哪些摘要"。

它与 Ferrando 的顺序一致：先用独立行为定义坐标，再在表现最差的格上检验，最后才干预。它也是隐藏态进入研究的唯一通道：只有当某个格的残差异质性用自动文本特征解释不掉、而 t₀ 隐藏态的线性探针能解释时，隐藏态坐标才获得行为意义。

### 3.5 开环与闭环在同一批随机化，遮断只做在出现交互处

固定填充轮的生成成本接近零，自由回答每条对话多一到两条回答。两者在同一批题目上随机分配，同种子配对，可以免去第二轮生成。遮断旧首句的配对分支按负责人意见只在出现关键交互的条件上做。若闭环交互在遮断下缩小，再做一次文本反事实（把自写首句换成中性措辞、保留正文），分开"回读"与"内容"，这相当于把已登记的 P2-1d 搬到新材料上。

### 3.6 零成本记录隐藏态与首词分布

每个前缀在 t₀ 的三到四层隐藏态与首词分布在生成时顺手记录，每个前缀几百 KB，不分析不训练。它保留了两项选择权：3.4 的审计需要时可以立刻做线性探针；将来若决定训练受控闭合编码器，不必重新生成。不记录则每次回头都要重跑。

### 3.7 第二族预登记为"可推导性相反"的族

第一族选已有可靠自动评分的程序语义，理由是基础设施现成：执行甲骨文、答案匹配构造、旧解释器记录作不适用证据。但程序族是事实可推导的族，路径对事实的效应在这里已知很小；若七格在这里事实交互为零，不能推广到不可推导的事实。所以第二族应在第一族生成的同时开始构造，并预登记为可推导性相反的族：记忆型事实（Wikidata 型真值，别名表做自动评分），它是书目的可扩展替身。书目 9 部作品只作最终确认。这样第二篇的通用性主张至少立在两个可推导性相反的族上，而不是无限期推迟。

## 4. 规模与功效

设格内采纳率 p ≈ 0.3，每格 r 次重复，题目聚类的设计效应约 2。四格交互在概率尺度上的标准误约 sqrt(4·p(1−p)·2 / (r·n)) = sqrt(0.42/n)（r = 4）。

| 每层题目数 n | 交互量标准误 | 80% 功效可检出的交互 |
|---|---|---|
| 60 | 0.084 | 约 0.23 |
| 150 | 0.053 | 约 0.15 |
| 300 | 0.037 | 约 0.10 |

同种子配对会降低一些方差，r = 8 再降约三成。含义：60 题的试点只能排除 0.2 以上的交互，它的零结果不足以写"无交互"。建议第一族每个层（侧别 × 证据档）120 到 150 题，预登记最小可检出效应。生成量：七格 × 150 题 × 4 次 × 3 层（首答正确侧两档证据、首答错误侧一档）≈ 12,600 条对话，开环只有末次追问一条回答，闭环多一到两条，合计约 25k 条回答、约 5M 词元。瓶颈在题目与证据文案的构造，不在生成。按零压力普查把首答确定性控制在 0.25–0.75，避免饱和。

## 6. 主问题措辞

主问题采用负责人的句子：在同一道题、同一个用户主张下，先施压再给证据与先给证据再施压，是否会以可预测的方式改变模型最终答对的概率；模型自己上一轮写下的回答，在其中起了什么作用。

建议加一句次级预登记主张，使通用目标不从视野中消失：预测这种改变所需的状态，能否由少数行为测试定义、逐轮更新，并在可推导性相反的第二个任务族上不重训地复用。主问题答不出时次级主张自动不成立；主问题答出而次级主张不成立，就得到"任务内的动态预测器"，同样如实写。
