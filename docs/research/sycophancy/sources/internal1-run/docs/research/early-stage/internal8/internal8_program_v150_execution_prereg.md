只有事实标签或最终答案发生配对变化，才能讨论下游状态对事实回答的影响；文字分叉本身只说明输出变化。有变化不自动等于总体改善。无变化只约束所测材料与指定操作，不排除全部间接路径；零事件的条件性上界注明固定材料与抽样独立性假设，不能将退化题簇重抽当成总体等效。
