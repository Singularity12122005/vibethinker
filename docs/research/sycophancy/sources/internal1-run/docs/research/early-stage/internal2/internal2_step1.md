## 登记原句与两种推断的差异

下列原句摘自[执行指令](../../sycophancy-phase0-internal2-directive-step0-1.md)及[设计第二版](../../sycophancy-phase0-internal2-design.md)，上文按主变体和并列变体逐项给出实际判读。

> 弥合比例 $\le0.1$（1:1）。

> $d^{\rm neu}$ 池化点估计 0.55–0.75，判"有限"或"未定"。

> 弥合比例 $\le0.2$，并落在 1.3 曲线对应 AUROC 的 ±0.1 带内。

> 两等式的区间都含 0 且 0.1 的比值 $\ge0.8$，记"提示干预共用条目排序"；任一斜率差区间不含 0，记"$H_9$ 条目层复活，待第 3 步分辨是读出方向还是过程"。

v1 的近似似然比检验中，以下名义 p 值低于 0.05：status : F-D minus S_T（hierarchical，p=0.03469）。相应作品簇重抽差值区间仍含零。登记的共用排序组合判据采用区间，但两种推断的差异须保留，不能据此确认斜率相等。

v2 的近似似然比检验中，以下名义 p 值低于 0.05：S_T : status minus A1（firth，p=0.00651），status : F-D minus S_T（firth，p=0.01734）。相应作品簇重抽差值区间仍含零。登记的共用排序组合判据采用区间，但两种推断的差异须保留，不能据此确认斜率相等。

主变体状态格式跨单元的层次模型无先验似然比，初次优化未收敛；保持数据和模型，改用 64 点自适应积分及数值差分优化求得两项边际似然。该核对无需被试前向。

按设计指定的等方差高斯模型求贝叶斯最小损失，先验取 39/70，使用两单元冻结的两臂经验损失。标准化均值差为根号二乘判别曲线下面积的标准正态分位数。主变体点估计低于设计所举的 0.60–0.90 范围，参考带为同一分布模型的外推。。历史读数来自既有读取函数，按 23 个单元内作品与已发表的第二轮坚持、首答一致性及历史数核对，全部吻合。
