# 十例提案的结局盲判

判者看告警前的公开历史和模型在分支前共写的账本，不读取分支动作与评分。判者参与过部分材料恢复、分层和参考修法设计，属于对生成结局设盲。判断的是模型提出的实际命令，与人工可能另行设计出的好检查分开。

“重复”指在产品状态、输入和有关环境未改变时再次索取前缀已给出的同一观测。只读源码可以揭示新事实。“分流”要求检查能在当前状态观察到模型所说的差别，而且两个返回分别对应不同且具体的下一实质编辑或有根据的停止。若一侧只表示“继续研究”，另记为不充分。无法在分支前判明的保留未定；代码命令的真实成功、失败应由独立执行侧另行报告。

| 案例 | 检查是否重复 | 能否据此区分后续编辑 | 默认命令 | 命令与前缀依据 |
|---|---|---|---|---|
| `sympy-17139` | 是 | 否 | 明确尝试新编辑 | `python3 test_cos_i.py` 重跑末条已触发第 506 行异常的脚本。默认命令拟改那一行；“若修改完成便停止、若转移到下一行就继续改”的预言适用于修改后复测，当前检查副本尚未执行该修改。 |
