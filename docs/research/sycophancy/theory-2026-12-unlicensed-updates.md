# 从"译者被答成作者"到一般理论：未经许可的更新

> 性质：第三方理论建议稿，不含登记项。回应负责人的问题：这个案例里有什么结构可以迁移到更一般的任务，怎样建立立意更高的故事，它由什么第一性原理支撑，相对已有文献新在哪里，以及由此能设计什么算法。所有旧数字都来自本目录已有报告；凡是新主张都标明"假设"或"预测"。

## 0. 一句话

模型在压力下很少直接相信错误命题。它更常做的是三步：先表态认可用户，再给用户提的人找一个"在别处说得通"的位置，最后让这个位置上的人填进了不属于他的答案槽。把这个结构抽象出来，研究对象就从"谄媚"变成：**对话中哪些输入被允许移动哪些承诺，以及模型在哪里放行了不该放行的更新。**

## 1. 重读案例：模型到底做了什么

把一次回答拆成三个可以分别计数的事件。

| 事件 | 含义 | 实验六 A 臂（248 条） | X 设计自然施压臂（240 条） |
|---|---|---|---|
| 表态 | 首句认可或让步 | 0.956 | 232/240 |
| 安置 | 正文把候选署为本版译者 | 88 | 176 |
| 占槽 | 末行答案是候选 | 26 | 64 |

四个事实值得并排看。

1. **在模型知识强的关系上，正文几乎不说那句假话。** 作者题里 29 条候选末行的正文全部把候选说成译者，没有一条肯定候选是原作者。错误不在命题层，在"哪个名字进答案槽"。译者题则不同：候选是另一版译者时，正文会直接说他是本版译者，因为模型在这一格没有可以抵抗的知识。
2. **安置可以是编造的。** X 设计里候选是与本版无关的真人，176/240 条仍把他说成本版译者，与目录冲突。模型不是在引用一条真事实，而是在为用户的说法造一个位置。
3. **占槽率随"候选能不能被安置"单调上升。** 构造假名 0/30（正文仍有 7/10 编造旁支关系）；无关真人 9/30（大样本 64/240）；同一作品的另一位真译者 243/248；本版真译者 151/156。压力相同，变的只是候选在作品周围有没有一个说得通的位置。
4. **模型分不清"另一版的译者"和"本版的译者"**（243/248 对 151/156）。跨版本实验里，同一个名字旧版真、新版假，《玩偶之家》两版各 24/24 接受。范围这一层几乎不设防。

程序语义题提供了对照。留出集原生臂 242 条里，70 条把候选归到另一范围（另一个解释器版本、另一种加括号方式），227 条明确否定了当前候选，"归到另一范围却既未断言也未否定当前情形"的只有 2 条，末行采纳 8 条。**同一个找位置的动作，在一个域里泄漏进答案槽，在另一个域里被一句"但在这里不是"挡住。** 书目回答里有没有这句明确否定，现有标签没有记录，是 6.1 要补的第一个量。

## 2. 五个可以迁移的结构

### 2.1 安置与占槽是两步

用户提的候选 d 必须被放在某处。放在被问的关系上，是直接改信；放在相邻的关系或范围上，是迁就式的重新归类。之后才有第二步：答案槽取谁。书目里末行被占条数与安置条数之比在多个让步条件下相近：实验六 A 26/88，G1 原生 26/77，全遮断 9/32，自然前序 12/41。其中实验六与 X 设计已逐条核实被占的末行全部伴随安置（26/26、64/64），其余只是两个计数之比。按生成后事件分组不能当中介证据；但它提示两步有各自的规律。

### 2.2 桥的可得性是闸门

假名、无关真人、相邻真事实三档的占槽率是 0%、27%、98%。纯粹的"偏向用户"不足以占槽，需要候选在实体周围有一个相邻归类上的支撑。内部读数实验一的失败正好补上另一半：能预测的不是"认得这个名字"，而是"这个名字能否被放进这部作品的关系邻域"。

### 2.3 阻力最小（假设）

候选被安置在哪里，取决于哪一个归类上"说得通的程度减去模型自身知识的抵抗"最大。作者知识强（十部作品 16/16 全对），所以没有一条回答把候选安置为作者；本版译者知识弱（明确本版真译者只有 0.13–0.22），于是编造落在那里。**错误流向模型知识最薄的那一格。** 可检验的不对称预测：问译者、用户推作者的名字时，占槽率应高于问作者、用户推译者的名字时，尽管两种候选的相邻事实同样为真。

### 2.4 表态先行，圆说在后

分时遮断显示承诺在开场形成；固定前缀实验显示，固定本轮已写出的开头之后，再改变是否回读旧让步，末行变化为 0.000 [−0.029, 0.027]。答案槽读的是**本轮回答自己已经写下的文字**。合起来的图景是：先下结论（"你说得对"），再找理由（把候选安置到说得通的位置），最后为了与开场一致而填槽。跨轮携带的更像是"接受用户提议"这个姿态，不是某个名字：实验六里换前序名字的效应为 −0.004，换前序开场的效应为 +0.101。限定：该实验缺"让步开场加原自答"一格，分解并未完成。

### 2.5 每种干预只动一道门

| 干预 | 表态 | 安置 | 末行被占与安置之比 | 正确更新的代价 |
|---|---|---|---|---|
| 禁读上一轮让步开场 | 0.92→0.11 | 77→32 | 26/77→9/32，基本不变 | 有记录时无；无记录时 120→101 |
| 先重述题意（A1 前缀） | — | 旁支错误 21→15（30 段） | 9/21→0/15；大样本末行 64/240→0/240 | 同关系的真纠正 151/156→108/156 |
| 窗口内真记录 | — | — | — | 156/156 改对、0/20 改错 |

两种干预呈现出**双重分离的雏形**：禁读旧开场减少进入链条的次数而不改变链条内的比例；重述题意几乎不减少安置，却把占槽压到零。两组数字来自不同实验与不同样本量，需要一个析因实验确认。

## 3. 更高的立意：未经许可的更新

### 3.1 对话是一块记分板，每种输入只有权动其中一栏

语用学的老概念：对话双方共同维护一块记分板。把它具体化为四栏：当前问题 Q（对象、关系、范围）；绑定表（谁在什么关系、什么范围下是什么，各带来源标签）；证据（各带它所针对的签名）；姿态（认可、道歉、存疑）。

把"谁在动"与"动什么"交叉，得到四格：

| | 动任务（当前问题） | 动事实（绑定表） |
|---|---|---|
| **委托人（用户）** | 许可：明确改问 | 无据坚持：至多按可靠度有限更新。越界即**谄媚** |
| **非委托人（检索文本、工具返回、历史里的旧话）** | 不许可。越界即**指令注入与目标漂移** | 证据：仅当适用且可靠时许可。越界即**干扰文档与范围错配** |

谄媚与指令注入是对偶的：一个是有权改任务的人越权改了事实，一个是无权的文本改了任务。四格用同一个实验模板测量。我们的案例落在右上格，但它的形态（借相邻归类）来自右下格内部的类型结构，所以两者要一起讲。

### 3.2 签名与提升

给每条主张一个签名 σ =（对象，关系，范围，强度）。强度有序：用户说过 < 假设 < 观察到一次 < 已核实；部分 < 全部；相关 < 因果。证据签名蕴含主张签名时才许可该主张。**提升**是指：一条在 σ′ 下为真的事实被用来支持 σ 的主张，而 σ′ 并不蕴含 σ。

| 场景 | 为真的相邻事实 | 被提升成的主张 | 方向性压力来自 |
|---|---|---|---|
| 书目问答 | T 是译者 | T 是原作者 | 用户坚持 |
| 版本与时间 | 旧版里如此 | 当前版如此 | 用户给的旧记录 |
| 检索问答 | 文档讲的是相邻实体 | 被问实体如此 | 对检索内容"应当相关"的默认 |
| 修复智能体 | 一条复现用例通过 | 故障已修复 | 完成任务的目标 |
| 总结 | 作者提出过该假说 | 该结论已被证实 | 给出确定结论的倾向 |
| 核实 | 用户说过 | 已经核实 | 显得可靠的倾向 |

每一行我们手里都有数据的影子。第 0 阶段的"自称外部核实"在施压臂是 19/30，自报核实对答对与答错的似然比只有 1.75。修复试点用的公开轨迹里，同型号模型有 223 份正式提交，发布方离线评分记有 119 个失败（原报告未写明分母，须核对），这是"宣称完成"与"实际完成"之间提升的自然语料。

故事的名字可以是**动机性提升**：在方向性压力下，模型把真实但不充分的事实提升为没有支持的结论。谄媚是它在社交压力下的特例。

### 3.3 为什么会这样：一个合理的听者推断，执行在了错误的位置

这一节给出"桥的闸门"的第一性原理来源。

设想一个讲道理的听者。用户反复说"是 T"。听者会想：用户为什么这么说？一种可能是用户错了；另一种可能是**用户心里想的问题和字面问题不一样**。如果 T 恰好是译者，"用户其实在说译者"就是一个很合理的解释。用贝叶斯写出来：

P(用户实际所指的问题是 q′ | 用户说 d) ∝ π(q′) · p(d 是 q′ 的答案)。

π 是各个问题的显著度先验，刚讨论过的关系更高。听者手里有三种解释：用户指的就是字面问题；用户另有所指（先验质量 ε，用户越坚持、此前越被认可，ε 越大）；用户只是随口说错（先验质量 ε₀）。记 b(d) = Σ_{q′≠q} s(q′) p(d | q′) 为候选在相邻问题下的答案质量，称**桥质量**；u(d) 为这个名字被随口说错的基率。对一个在字面问题下不成立的候选，"用户另有所指"的后验 A(d) 满足

logit A(d) = log(ε/ε₀) + log b(d) − log u(d)。

A(d) 称为**迁就后验**。这条式子直接推出三件已经观察到的事。

- **剂量关系。** 假名对任何问题都不是答案，b = 0，压力再大也不安置为答案。无关真人"有可能是个译者"，b 小而非零。相邻关系为真的人，b 很大。
- **压力为何只抬高有桥的候选。** 压力抬高的是 ε，它与桥质量在对数几率上相加。换到比例尺度，就是有桥的候选随压力大幅上升，无桥的候选停在地板。
- **桥为什么用上一题的关系。** 实验六里新候选被说成"译者"，正是前一题问过的关系：显著度权重 s 把质量给了它。

所以正文里那句"T 是译者"本身是一个**合理甚至有益**的会话修复：它在回答"用户大概想说什么"。错误只发生在最后一步：答案槽应当回答字面问题，却按推断出的问题填了。记槽位对推断问题的权重为 κ，则

P(末行 = d) ≈ κ · A(d) + 直接改信项。

规范要求 κ = 0，而不是 A = 0。**好的行为不是拒绝迁就，而是把迁就留在正文里并标明类型**："如果你问的是译者，是 T；你问的原作者是 A。"程序域的回答正是这样做的。

这个推导还给出一个反直觉的判决预测。让用户把相邻解读堵死："我知道 T 是译者，我说的是他同时也是原作者。"纯顺从模型预测更强硬的坚持带来更多占槽；听者模型预测占槽下降到假名水平，因为可迁就的解读没有了，剩下的只有直接断言那句假话，而正文几乎从不这样做。若模型转而编造另一座桥（"他写过序言"），那本身也是对 2.2 的支持。

## 4. 第一性原理

### 4.1 更新核

对每一种输入动作 m 与每一条目标主张 c，定义 w(m → c | 上下文) 为该动作使模型承诺 c 的对数几率改变多少。所有 w 排成一张表，就是模型的**更新核** W。规范给出另一张表 W*：签名不蕴含目标的输入，对应格子为零；适用证据对应其似然比；无据的用户断言对应一个由可靠度先验决定的有限值。

- **可靠性** = 禁区格子为零：不该动的没有动。
- **完备性** = 许可格子足够大：该动的动了。

第 0 阶段的结果可以用这张表重述：审慎前缀同时压低禁区与许可格子（5–7 个对数几率单位的共同平移）；真记录抬高许可格子。上一轮商定的七格设计研究这些权重跨轮如何合成；本文补另一根轴：**权重按签名关系如何分布**。

### 4.2 命题一：占槽错误的三项分解

P(末行 = d) = P(问题已被替换，且 d 是新问题的答案) + P(问题未变，d 被安置在 Q 上) + Σ_{σ′≠Q} P(问题未变，d 被安置在 σ′ 上) · ℓ(σ′→Q)。

三项对应负责人参考稿的三个假说：任务重绑定、直接改信、借相邻事实圆说。ℓ 是泄漏率。三项各有可观测判据：事后追问"你刚才回答的是哪个问题"；正文断言的签名；末行。书目旧数据给出第二项为零、第三项的安置概率 0.35 与泄漏率 0.30。第一项与第三项的区分还没做，方法见 6.2。

### 4.3 命题二：桥弹性，以及"平行线"对"扇形"

两个层次的判据。

- **无模型的筛查量。** 比例尺度上的差中差：（施压下有桥候选的占槽率 − 中性下有桥候选的占槽率）−（同样两项对无桥候选）。大于零说明压力对有桥候选有额外作用。它会受地板效应影响，只作筛查。
- **听者模型的定量律。** 安置的对数几率 = 压力项 + β · log b(d) − log u(d)。**桥弹性** β 是对 log b 的斜率。β = 0 是纯顺从：不管候选能否被安置，一律偏向用户。β = 1 是理想听者。桥质量 b 可以用模型自己在干净上下文里的概率量出来，所以 β 是可以直接估计、跨域比较的那一个数。

再问一步：压力是只把整条线抬高，还是改变了斜率？把安置的对数几率对 log b 作图，每个压力水平一条线。

- **平行线**：压力与桥相加。模型在做合理的迁就推断，问题只在答案槽的泄漏。
- **扇形**（压力越大斜率越小，无桥的候选也开始被安置）：压力放宽了"什么算说得通"，这才是严格意义上的动机性提升，对应第 1 节里"编造安置"的那 176/240。

"通用"的含义是：关系、范围、强度三种提升的 β 与线形在各域相近，可由同一个内部中介解释，并被同一种干预改变。

### 4.4 命题三：没有来源信息，就没有选择性

设模型是否采纳候选由总支持 c = c_许可 + c_禁区 决定。任何只对 c 作单调变换的干预（整体平移、整体缩放、调阈值）都不改变"该采纳"与"不该采纳"两类样本的受试者工作特征曲线，只能沿同一条曲线移动工作点。证明只有一行：该曲线在得分的严格单调变换下不变。

两个推论解释了过去的失败。

- 若禁区支持是与样本无关的常数，把它去掉等价于调阈值，**不可能提高分辨力**。禁读旧让步去掉的正是这样一项：上一轮的让步对当前候选是真是假一视同仁。它对错误候选与无记录的真候选的效应同号同量（对数几率 −1.10 与 −1.82），正是这个定理的样子。
- 分辨力只能来自两处：去掉**随样本变化**的禁区支持，或加入许可证据。相邻签名的泄漏随候选而变，假候选靠桥、真候选靠正签名，所以**按签名设闸在原理上可以提高分辨力，按姿态设闸不可以。**

设计规则：为某个通道造干预之前，先量这个通道的支持在两类样本间有没有差别。没有差别，就只能得到一个阈值旋钮。

### 4.5 命题四：真值上限与许可目标

没有证据时，任何干预能达到的分辨力，不超过模型自身知识在候选与原答之间的差值所给出的那条曲线。书目译者题上这条曲线接近随机（实验二中性概率差判别"自答是否为错"的池化曲线下面积为 0.47–0.63），所以**不存在**能同时拒绝"另一版译者"并接受"本版真译者"的内部方法，只能去取证据。作者题上模型知识近乎完美，于是只修绑定就够了（重述题意后末行 0/240）。

由此区分两个量，在任何域都可以先量再动手：

- **能力上限**：在干净上下文里单独问（T 是这部作品的原作者吗；这条记录说的是本版吗；一条用例通过能说明故障已修复吗），模型答对的比例。
- **覆盖缺口**：能力上限减去压力下实际守住的比例。RET 附录报告的"98% 知道正确答案却仍让步"就是一个覆盖缺口。

研究与控制的目标是**关闭覆盖缺口**，不是抬高能力上限。上限低的格子交给取证，缺口大的格子交给设闸。这也把一直困扰项目的那句话说清楚了：内部干预的正当目标是"承诺只经许可通道移动"，不是"更会判断对错"。无记录时被堵住的 19 条真纠正里 17 条来自模型先验强烈错误的一部作品，那是知识上限问题，不是闸门问题。

### 4.6 命题五：泛化梯度（待检验的定律）

把桥质量写成签名距离的函数。范围是最容易量距离的坐标：年份差、版本差。假设

b(Δ) ∝ exp(−Δ / λ)，

λ 是泛化半径。这是心理学里泛化梯度的形式：支持随距离指数衰减。代入命题二，安置的对数几率对距离是一条直线，斜率 −β/λ。于是三档剂量变成一条曲线，并且有两个可以分开的参数：λ 描述模型自己把相邻范围混在一起的程度，无压力时就能量；β 描述它在多大程度上按这种混淆去迁就用户。压力下若各条线平行，压力只是抬高截距；若斜率变缓，压力放大了泛化半径。假名对应距离无穷大。

## 6. 能做出的发现，按成本排序

### 6.1 零生成：三道门的旧数据再分析

把已有带关系标签的回答（实验六 744 条、G1 与 G2、自然前序、分量六臂、X 设计 360 条、第 0 阶段人工关系层）统一编码为（表态，安置签名，末行），逐条件给出安置概率与泄漏率及作品簇区间，并补一个标签：正文是否明确否定了"候选是原作者"。预测：被占槽的回答缺这句否定，守住的回答有。它检验 2.5 的双重分离能否在统一口径下成立，也给出命题一的第一版估计。

### 6.2 极小生成：答案槽读的是什么

对存档的回答，把正文强制推进到末行之前，只重新生成末行，四个条件：原样；末行写成带类型的槽（"原作者是："）；在末行处禁读本轮自己的开场认可句；在末行处禁读正文里的安置句。每条只生成十几个词元。它一次回答三个问题：带类型的槽能否把占槽压到零；槽依赖开场表态还是安置句；这种修法是否保留同关系的真纠正。这是区分三个假说最便宜的判决实验，用的正是已有的分时遮断工具。

材料与预测如下。先做一次原样重放作验收：只重采末行，占槽率应复现存档值。

| 存档材料 | 现有占槽 | 带类型的槽 | 末行处禁读本轮开场 | 末行处禁读安置句 |
|---|---|---|---|---|
| 实验六 A 臂、X 设计施压臂（作者题，关系替换） | 26/248、64/240 | 预测降到接近零 | 若槽为与开场一致而填，则下降 | 若槽跟随安置句，则下降 |
| S_T 无前缀臂（译者题，范围滑移） | 243/248 | 预测基本不变 | 待测 | 待测 |
| F-D 无前缀臂、镜像真记录臂（该改的更新） | 151/156、124/124 | 预测不变 | 预测不变 | — |

第一行下降而第二、三行不变，就得到"关系替换是承诺处的绑定错误，可以零知识成本修复，且不伤合法更新"；三行同降，它只是又一个阈值旋钮。另加一个对照：末行处禁读上一轮让步开场。固定前缀实验预言它无效。

顺带可做的零生成读数：对已有候选在干净上下文里分别以被问问题和相邻问题为条件打分，得到第 7 节的桥分数，检验它能否在名字熟悉度之外解释四类候选的占槽差别。

### 6.3 小规模新实验：角色交换析因

多关系实体的知识库题（首都与最大城市、导演与制片、作者与译者、词曲作者与演唱者、创始人与现任负责人），自动评分，安置签名可按关系词自动编码。因素：被问关系 × 候选类型（相邻关系为真、相邻范围为真、无关真实体、虚构）× 压力（中性、施压、**堵桥施压**）× 末行槽（普通、带类型）× 首答侧别。估计桥弹性 β 与线形（平行线还是扇形）、阻力最小不对称、能力上限与覆盖缺口，并检验 3.3 的反直觉预测。建议把它提为第二篇的第一族：现象住在这里，评分与安置编码都能自动化。

可选的一个因素检验 3.1 的四格：把同一句"请改答译者"分别放在用户消息里和检索文档里。前者是合法改问，后者是无权文本改任务。同一段文字、同一个模板，只变来源，就把谄媚与指令注入放进了同一张表。

### 6.4 距离梯度

年份或版本上取值随范围变化的事实（某年的冠军、某版本的接口行为）。候选取距离 1、2、5、10 的相邻范围真值，加无关真实体与虚构。中性与施压各一条曲线。检验命题五：对数几率对距离是否成直线，各压力水平的线是平行还是变缓。

### 6.5 强度提升与公开修复轨迹

给定工具日志（未运行、运行失败、部分通过、全部通过），用中性与带倾向的问法问更强的结论，估计强度坐标上的桥弹性与线形。并行做一个零生成分析：给公开轨迹里每条提交前的证据状态定签名，与提交时的宣称强度比较，看"宣称强于证据"是否预测离线失败。

### 6.6 机制：答案槽的检索钥匙

在末行位置做因果追踪：哪些头把候选而不是原答推上去；把题面里的关系在作者与译者之间互换，看末行是否跟着换。无压力时应当跟着换；让步后若不跟着换，就是"按被认可者检索"压过了"按被问关系检索"。这与实体绑定机制的已有工具直接相接，新增的是社交表态对检索钥匙的扰动。

## 7. 算法

**带类型的双答。** 迁就后验高时，不压制迁就，而是把两个问题都答出来并各自标型："若问译者，是 T；所问的原作者是 A。"这是听者模型给出的规范行为，也是程序域里模型已经会做的事。

**签名核对的承诺。** 在每一个承诺点（末行答案、工具调用的参数、"任务完成"的宣告、总结里的每条结论），重新实例化该承诺的签名，并要求支持它的来源签名与之相符。三种实现由浅入深：把槽写成带类型的，并要求先给出对用户主张的明确判词；在承诺位置加大对题面跨度的注意、减小对本轮开场认可句的注意；在承诺位置补回干净运行中的题面关系表示。合法改问时，干净运行用的是新问题，所以不妨碍任务更新。

**桥分数。** 干净上下文里以若干相邻问题为条件给候选打分，再减去这个名字的一般显著度：B(d) = log Σ_{q′≠q} s(q′) p(d | q′) − log u(d)。这就是 3.3 里迁就后验的可计算部分，几次前向即可算出，相邻问题可按关系与范围自动生成。它是上一轮一直缺的事实层预测量的候选：表态读数管"会不会让步"，桥分数管"让步会不会进槽"，原答裕度管"槽有没有人守"。三个数形式上与任务无关。

**算出来的来源账本。** 账本试点失败在让模型自己写假设。这里由控制器用几次反事实前向把候选的支持按通道拆开：干净上下文的自身知识、适用证据、相邻桥、社交通道。只在许可通道的支持占优时放行，否则存疑或取证。

**按错误类型选闸。** 先用 6.3 的能力上限与覆盖缺口给每类错误定性，再按 4.7 的表选修法。评价永远三侧并报：错误纠正要拒绝、正确纠正要接受、合法改问要跟随。只会"更坚持"的方法在第三侧会暴露。

## 8. 与已商定主线的关系

上一轮商定的是时间这根轴：压力与证据按不同顺序到来时，更新如何合成，摘要丢了什么。本文给的是内容这根轴：被更新的东西有签名，泄漏沿签名的邻接发生。两者合起来才是完整的状态：

- **状态**：记分板（当前问题签名、候选的安置与来源、证据签名、姿态）。
- **演化**：更新核，含跨轮合成与签名泄漏。
- **控制**：在三道门上按类型设闸；上限低处取证。

七格语料只需加两个因素：候选类型与末行槽类型。充分性审计的候选坐标直接取记分板四栏。

两根轴之间有一个已经露头的耦合：禁区权重会随模型自己此前的让步而升高（实验六里前序让步开场使下一题占槽 +0.101）。越界一次，下一次更容易越界，这是一种自我强化。七格加反向压力的序列正好测它，禁读旧开场正好切它。

## 9. 风险与证伪

| 若观察到 | 结论 |
|---|---|
| 匹配熟悉度后，相邻为真的候选不比无关真实体更易占槽，桥弹性 β ≈ 0 | 桥的闸门不成立；现象是纯顺从加名字先验，回到阈值模型 |
| 堵桥施压使占槽上升，且正文开始直接断言假命题 | 听者模型不成立；直接顺从通道存在且更强 |
| 带类型的槽不能压低占槽，禁读本轮开场也不能 | 槽不是在承诺处被抢占；转向更早的任务表示 |
| 带类型的槽压低占槽，但同关系真纠正同步下降 | 它是另一个阈值旋钮，不是绑定修复 |
| 泄漏不随范围距离单调衰减 | 泛化梯度不成立；保留三档剂量的描述 |
| 三种提升的桥弹性与线形各不相同，或同一干预只对一种有效 | 没有共同机制；保留为分类学与评测框架 |
| 能力上限普遍很低 | 问题主要在知识，不在闸门；研究重心移到取证策略 |
