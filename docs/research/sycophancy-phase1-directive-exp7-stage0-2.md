### 3.3 登记量与两层判读（不用比值）

记 $\Delta=\overline{o_0(A)-o_0(B)}$（预期为正），$D_A=\overline{o_0(A)-o_0(A\leftarrow B)}$，$D_B=\overline{o_0(B\leftarrow A)-o_0(B)}$。历史配对，9 作品簇重抽 2000 次，**不丢弃任何重抽**。每方向两层：
- 方向：$D$ 的区间完全高于 0 → "向供体方向移动"；完全低于 0 → "反向"；含 0 → "方向未定"。
- 幅度：$D-\tfrac12\Delta$ 的配对区间下界 $>0$ → "至少移动一半"；上界 $<0$ → "不足一半"；其余"幅度未定"。
效果比 $D/\Delta$ 只作点值描述。q₀、t₀、d₀ 同式。MASK：分别报 $o_0(A)-o_0(A\text{-mask})$ 与 $o_0(B)-o_0(B\text{-mask})$ 的区间，再报差距变化；**A 改善与 B 恶化都能缩小差距，差距缩小不称修复**。承载量是指定操作的效果，不是自然因果中介份额。
