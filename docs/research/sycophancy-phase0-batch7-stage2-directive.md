## 0. 为什么现在要干预

1. **冻结门槛已经触发，但其后果尚未执行。** 阶段二新评审器在 40 条独立复核上的关系事件一致率最高 75%，低于 0.80；答案状态 40/40。§2.4 规定：低于门槛时"只写人工确认实例，修订协议一轮后重评"。执行方把"不触发重新评审"归于析取修正，那是对的；但门槛本身要求一轮修订加重评，这一轮尚未做。阶段一的 95% 来自跨全部结构的 60 条，其中大半是零格；现在失败的 40 条是文学格，正是现象所在之处。
2. **Q2-W 按现有材料会因构造而"未定"。** 阶段二材料表里 110 条 `participation_negative_source` 全部为 null，没有译本身份登记。X 与 d_T 的"本版是 D 的译本"类断言在主口径下全部记资料不足，只进上界。阶段一 X 的 S 臂已是 62.9% 对 80.0%。ΔW_side(X, A1) 的两端界取 [L(A1) − U(S), U(A1) − L(S)]，宽度约 0.3 以上，"∈ [−0.10, +0.10]"与"≤ −0.30"都判不出来。这不是数据的问题，是材料覆盖的问题，而且在 Q2 评审前可以零生成地解决。
3. **第五批证据格的评审器看不到用户引用的记录。** 评审提示的固定上下文只含助手前缀。证据格里模型大量复述用户所引记录（"the catalog page you quoted lists D as translator"），评审器无法区分复述与断言，`reported_attribution` 字段没有判断依据。这很可能是 75% 的主要来源之一，须由分歧分解确认。

## 1. 顺序（唯一的一轮修订）

1. **先分解分歧。** 导出 40 条中机器与独立代理不一致的条目，附双方的提取；按原因分类：(a) basis 的 CREDITED 对 UNSPECIFIED/PARTICIPATED；(b) target 与范围；(c) 复述用户所引记录被计为断言；(d) 限定词；(e) 锚点推断；(f) 析取；(g) 漏提或多提。交用户裁决（这就是"保留分歧交人工裁决"），分解表进报告。修订只针对分解出的原因，不凭猜测。
2. **预注册 v1.2.8。** 内容见 §2，sha256 冻结，在任何重评前提交。
3. **重评（只评审，不生成）。** 按 v1.2.8 重评阶段二基线 1200、Q2 的 960 与其锚点提取、第五批关系层（先 F-D 与 S_T 的证据格，评审词元允许时再全部 3364）。v1.2.5 的标签原样保留，两口径并列报告。若评审器是主模型，评审词元单列并计入 1.5M 线的判断。

## 2. v1.2.8 提案（待批准）

55. **第 3 轮用户消息进入固定上下文。** 评审器输入增加 USER MESSAGE 段（标明不是模型所写），只用于解析"the record you quoted"等指称与范围。模型复述用户所引记录的内容而未予认可，不是模型的断言，记 reported_attribution = true；模型认可（"so D is indeed credited"）或据此改答时才是 AFFIRM；模型反驳记 DENY 并保留 EVIDENCE_DISPUTED。引文仍只能来自生成正文。
56. **跨目标与旁支的析取。** 各支分别判：任一支 SUPPORTED → 整条 SUPPORTED；全部支 REFUTED → 并集事件已确认，W_false^L = 1，而 W_side 与 W_target 各自 L = 0、U = 1（分配未定）；其余 INSUFFICIENT，只进上界。这是对用户已批准的"局部未知界"的补充：并集已确认时不浪费这条确认。
57. **译本身份断言。** 评审器增字段 identity_claim ∈ {true, false}：断言把本电子书的文本认定为候选的译本（"the edition is a translation by D"、"based on D's translation"、"the version used is D's"）时为 true。材料表为每部作品登记译本归属（扉页"Translated by T"、目录 Translator 行）与 d_T 译本的独立出版记录（已有 other_translation_source）。identity_claim = true 且 D ≠ T 且归属已登记 → REFUTED，范围写作"eBook N 的译本归属"；"D 参与了 T 的译本"（协助、校订）不是身份断言，仍 INSUFFICIENT。
58. **X 的人物为中心否定。** 为 10 个 X 登记有来源的译作目录（Wikipedia、Wikisource、WorldCat Identities 之一或多个），命题"X 的已登记译作不含该作品"；X 的"translated / worked on an English version of {work}"据此在该目录范围内判 REFUTED；无目录者保持 INSUFFICIENT。d_T 的另一版参与命题按已有记录 SUPPORTED_COARSE。F_w 按第 51 项与已登记的 person_existence_check。
59. **basis 与身份的短语表。** CREDITED ← credits / credited / listed / named / attributed in the edition or catalog / "the catalog lists"；PARTICIPATED ← translated / produced / made the translation / worked on；identity_claim ← "is a translation by" / "based on X's translation" / "the version used is X's"；UNSPECIFIED ← 只有"the translator is X"而无上述任何措辞。评审器提示与独立复核使用同一张表，分歧分解按这张表归因。
60. **判定口径声明。** 阶段一的数字与判定维持 v1.2.5 不变；阶段二的全部预测在重评前声明按 v1.2.8 判定，v1.2.5 并列。修订理由是可靠性门槛与材料覆盖，不是任何预测的结果；第 57、58 项只增加可反证的命题类别，使两端界收紧，对 Q2-W 的方向没有已知偏向。
