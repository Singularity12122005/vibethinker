### 1. 总判断

固定复述是"增益衰减器"，不是"决策恢复器"。它把社会证明压在生成前决策槽上的整行 $d$ 削去 17.2（区间 [−21.2, −13.2]），约为证词增量的六成；但起点太高（S_T 19.1），均值只回到 +2.0，没有过零，所以保序率只从 0 升到 0.23（C1"部分"）。真假对回复幅度的贡献是 1.76 个 logit（C4 区间 [0.19, 3.23]），不到复述总效应的一成。决策恢复的大部分由模型自己后续生成的正文完成：S_T 自答保留率沿"生成前 0 → A1 前缀 0.19 → 固定复述 0.23 → 模型自己第一句 0.355 → 末行 0.71"上升，真假之差也沿同一条轴从 0 增到约 0.4。真假敏感性不是在开局进入，而是沿生成逐步进入；A1 的价值不在前缀这句话本身，而在它启动的后续推导。

### 7. 对研究方向的含义

- **生成前决策槽是一个话语状态变量**：由最近的框架设定（证词 +27 / +14，点名 +14，作者题让步 +13，自述他人之言钉到 12，重锚定削六成），增益在组间几乎与真假无关，并在证词下饱和。知识进入这个槽的方式只是一个边际 $\alpha$（译者题 −8、作者题 −16.5），而这个边际在组间同样对真假盲（F-D 的 $\alpha(T)=-8.5$ 对 S_T 的 $\alpha(d_T)=-8.2$）。
- **真假敏感性是生成期现象**，其进入曲线可测（N1(a)）。实验三 B 的在线监测器应当与"差打开的那一句"上的在线动作配对；动态控制的位置在正文中，不在提示前缀。
- **固定前缀至多是增益旋钮**，任何带内容的重锚定效果相同；这个旋钮在末行是否够用，是 C″-1 要回答的问题（N2）。
- **让步框架是最危险的单一话语动作**：监测器应在末行之前就对"助手口中出现让步 / 复述用户名字"报警。
- **条目层脆弱性在压力到来前可由 $\alpha(N)$ 预测**（S_T 上 H10 成立）。

2. **可分离性的单元差异是实质信息**：F-D 的 $\alpha$ 与 $\Pi$ 皮尔逊相关 −0.84（VIF 3.4），S_T 0.06，作者题 −0.23。按 $\mathrm{Var}(d(O0))=\mathrm{Var}(\alpha)+\mathrm{Var}(\Pi)+2\,\mathrm{cov}$ 推算，F-D 的起点方差约 45，远小于 $\alpha$ 的 146：用户提出真名时，证词把所有历史压到同一个天花板，$\Pi_i\approx K-\alpha_i$；用户提出假名时（S_T）没有这种压缩（起点方差 ≈ 81 ≈ 45 + 34）。因此在 F-D，$b$ 的识别弱而 $g-b$ 恰是 $d(O3)$ 对 $\alpha$ 在固定起点下的斜率，仍可识别；而"真名证词饱和、假名证词不饱和"本身值得记为观察（描述）。
3. **开场之间**：$b_{O10}$ 最低（0.27–0.30），$g-b$ 最大（0.26）；放开 $g$ 后 $g_{O8}=0.79$ [0.71, 0.87] 对 $g_{O2}=0.41$ [0.34, 0.47]：带题名与电子书号的话题重述最多地保留模型自身的点名倾向，前缀加逐字原问保留最少。可读作"条目检索线索（题名、编号）重新激活条目特异的倾向，而原问全文把一切压平"，只作描述。

### 7. 对研究方向的含义与下一步（展开为实验五设计见 `sycophancy-phase1-experiment5-first-sentence-switch.md`）

1. **可控窗口被定位到三句以内。** 在复述开场之下，决策在第 1–3 句形成；监测器在第 1–2 句报警；之后干预只能改措辞不能改结论。在线动态控制的设计目标因此是"在复述之后、第 3 句之前"施加动作，而不是在末行。
2. **首句是分岔点。** 让步首句（base）导致译者题不可逆的采纳，作者题可逆；复述首句开启重新推导。控制上最便宜的杠杆是禁止让步首句、强制复述首句，这正是 A1 的机制；C″-1（N2）要回答的是脚本开场能否同样开启重新推导。
3. **动力学形式化（零前向，N1d(b)）。** 对每条续写的实测句末序列拟合 $d_{t+1}-d_t=\kappa_u(\mu_i-d_t)+e$，$\mu_i$ 按历史、$\kappa$ 按单元与臂；检验 base 臂 $\kappa\approx0$（无恢复力）、A1 臂与作者题 S 臂 $\kappa>0$，以及 $\mu_i$ 与 $\alpha'_i$ 的相关。序列只有 4–9 个点，用合并估计加历史随机截距，只在实测位置上做，不填行为终点。
4. **三分量回归（零前向，N1d(a)）**：见 §2(5)。
5. **N1b 与 N2 的优先级不变**：S−C 机制分解回答"证词把自答压下去的 12 logit 由哪些头承担"；N2 回答脚本开场能否开启前三句的重新推导。两行分解的共模核对若需逐词元对数概率，并入 N1b 的提取清单。
