## 第一部分 研究表述

### 1. 研究问题

**通俗版。** 模型在上一轮向用户让了步（"你说得对，我道歉"）。到下一个问题，它更常再次以让步开头，也更常把当前题用户提出的名字（与上一题的名字按设计不重叠）以替换后的关系写进答案：说这个人是本版译者，哪怕它明知这个人不是作者。跨轮传过来的是回答方式与关系选择，不是上一题的名字。我们问：下一轮的这个变化是怎么从上一轮传过来的；传过来的东西靠已写出的可见前缀延续，还是靠模型读那句开场时形成的计算状态延续；能不能只拦住"读那句话"这一步，让错误减少，同时模型在用户确实对的时候仍然改正自己。

**精确版。** 设前序助手回合 R1 与当前回答 R₂ 之间隔着一段逐词元冻结的共同问答。记 R₂ 在前序为让步式 R1 时的三个结局：候选进入末行 Y1、候选被署为本版译者 Y2、首句让步 Y3。已知：(i) 把 R1 的开场句换成角色提示句，Y1 下降 0.101；(ii) 生成 R₂ 时禁止所有查询位置直接读取 R1 开场句词元跨度，Y1、Y2、Y3 同时下降；只遮到在线确认点为止与全程遮相比，Y2 与 Y3 等效，Y1 未达登记的等效精度，整体早期充分性门未过。待答：这一早期读取的影响，经 R₂ 已写出的可见前缀、还是经前缀期读取规则所形成的计算状态传到确认点之后；该效果是否限于开场句跨度；去掉该读取是否降低有据纠错；在自然前序与跨作品目标上是否复现。

### 4. 工作假设与主线句

**工作假设（取代"让步首句是错误开关"的确定性版本）。** 前序让步表达在模型生成当前回答的最初几个词元期间被直接读取，改变这段回答的早期组织方式：以让步开场，把前一题所答的关系带入当前题，用当前题用户提出的名字以该关系作答。是否发展成错误，由当前关系约束、窗口内可用事实与模型对该版本的绑定知识共同决定。让步首句既非必要（O 下 14 条非让步错署）也非充分（真记录下大量让步仍答对署对）。

**现在可写的主线句（第 0 级，已有支撑；负责人第二轮评审稿）。** "在这些跨轮问答中，生成阶段对前序开场句的直接读取参与了后续错误署名和答案选择。错误署名具有明确的早期窗口依赖；入口强制读数的可移动性不能代替自然行为证据。下一步检验早期影响如何经可见前缀与计算状态延续。"方向层面可附的量：O−N 的候选末行与错误署名区间都排除 0；"至少减半"的区间判据未通过，不写"去掉大部分错误"。

**可并列写出的两条有界陈述（都是已测量的量，不是普遍否定）。** (i) 共同块与压力块缓存整体换入使入口末行读数移动超过原生差，而同一操作下候选末行与错误署名的变化被限制在原生差一半以下（四项半幅量区间上界 < 0）；(ii) 压力编码期遮前序正文对两项主要结局方向未定且不足减半，只遮开场句优于它有直接配对证据。不写"不由状态承载""行为不动""E 无效"：现有结果没有排除低于半幅的贡献、冗余路径或生成中的覆盖。

**G2 之后的主线句（建议稿，待负责人确认；在上句之后续写）。** "在固定前缀的交叉实验中，前缀包效应在两条分解路径、两个主要结局上都大于固定文字下的计算效应；给定相同的早期文字，前缀期是否读取前序开场对候选末行无检出差异，对切点后的错误署名只有小的反向差异。历史读取主要通过改变当前回答先写出什么起作用，先写出的内容再成为后续生成的条件。"不写"纯承载"，不写"内部状态无作用"，不写"只需控制首句"。

**完成点（修订）。** (a) 分清早期读取的影响经可见前缀还是经其计算状态延续，或两者共同；(b) O 在有据纠错上非劣，并量化无据真更新的代价；(c) 效果限于开场句跨度；(d) 在自然前序与跨作品目标上复现开场延续，并说明末行错误何时随之出现。
