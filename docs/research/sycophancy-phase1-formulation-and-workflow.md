## 第一部分 研究表述

### 1. 研究问题

**通俗版。** 模型在上一轮向用户让了步（"你说得对，我道歉"）。到下一个问题，它又以让步开头，并且把用户上一轮提出的名字放进这一题的答案位置，哪怕它明知这个名字不是作者。我们问：下一轮的这个变化是怎么从上一轮传过来的；传过来的东西是一句话的文字、还是模型读那句话时形成的内部状态；能不能只拦住"读那句话"这一步，让错误消失，同时模型在用户确实对的时候仍然改正自己。

**精确版。** 设前序助手回合 R1 与当前回答 R₂ 之间隔着一段逐词元冻结的共同问答。记 R₂ 在前序为让步式 R1 时的三个结局：候选进入末行 Y1、候选被署为本版译者 Y2、首句让步 Y3。已知：(i) 把 R1 的开场句换成角色提示句，Y1 下降 0.101；(ii) 生成 R₂ 时禁止所有查询位置直接读取 R1 开场句词元跨度，Y1、Y2、Y3 同时下降，且下降量在"遮到在线确认点为止"与"全程遮"之间等效。待答：这一早期读取的影响，经 R₂ 已写出的前缀文字、还是经前缀期形成的缓存状态传到确认点之后；该效果是否限于开场句跨度；去掉该读取是否降低有据纠错；在自然前序与跨作品目标上是否复现。

### 4. 工作假设与主线句

**工作假设（取代"让步首句是错误开关"的确定性版本）。** 前序让步表达在模型生成当前回答的最初几个词元期间被直接读取，改变这段回答的早期组织方式：以让步开场，把前一题的关系与用户提出的名字带入当前答案位置。是否发展成错误，由当前关系约束、窗口内可用事实与模型对该版本的绑定知识共同决定。让步首句既非必要（O 下 14 条非让步错署）也非充分（真记录下大量让步仍答对署对）。

**现在可写的主线句（第 0 级，已有支撑）。** "在多轮对话中，助手上一轮的让步开场会跨轮改变下一题回答的早期组织方式，使用户提出的名字以替换后的关系进入答案；这一影响由生成期对前序开场句的直接读取承载，而不由编码进当前压力消息的状态承载——后者可被整体换掉而行为不变；在生成的第一句窗口内禁止这一读取，无需任何事实即可去掉大部分相应错误。"

**完成点（修订）。** (a) 分清早期读取的影响经文字还是经状态延续；(b) O 在有据纠错上非劣，并量化无据真更新的代价；(c) 效果限于开场句跨度；(d) 在自然前序与跨作品目标上复现开场延续，并说明末行错误何时随之出现。

## 第二部分 实验计划

### 0. 通用口径（适用于全部各轮）

- **生成。** 冻结模型路径、分词器、专家与注意力实现不变；评估模式、无梯度、bf16、批量 1、从缓存接续；温度 0.7、不作前若干项或累积概率截断、重复惩罚 1、最多 1,024 新词元、结束词元 [151645, 151643]；冻结 SeededGumbelSampler，抽样流按（历史，重复）派生、同一实验命名空间内跨条件共用；新实验用新命名空间。被截断、循环、无首句、末行不可解析的续写全部进入分母并单列。
- **读出（标准集）。** 末行类别（own₂ / cand₂ / 其他）；首句动作与立场（冻结行为规则，名字保护后的句界合并）；关系三轴：候选被署为本版译者、本版错配并集、明确本版真译者、未命中本版译者断言、本版范围含混；当前关系作答正确；拒答与不可解析；连贯性三项（上下文外登记名字、与可见 R1 冲突的明确指向、指代不清的"先前"引用）。标签为规则命中，执行方代理复核，不是独立人工金标。
- **统计。** 每格每历史续写先平均，历史等权；9 作品共用权重 2000 次有放回重抽，同一报告内全部登记量共用每次重抽的权重；95% 双侧百分位区间；不丢重抽，抽中不足 3 个不同作品的重抽记不可定义并计数。两层判读：方向（区间排除 0）；幅度（"至少一半"= 相应半幅量的区间下界 > 0，"不足一半"= 上界 < 0；等效 = 区间完全落入界限内：候选末行 ±0.025、候选本版译者署名 ±0.05、首句与一般率 ±0.10）。5 作品材料用 Webb 六点权重（±√(3/2)、±1、±√(1/2) 各 1/6）的固定设计残差野自助 2000 次。全零事件报 95% 单侧 U = 1 − 0.05^(1/n)（固定材料、允许历史内相关、跨历史条件独立），并列 3/n。不作多重比较校正，报比较数。
- **门与停止。** 恒等与空操作门统一 1e−4（完整词表输出与缓存），非有限值、形状或跨度不一致同样失败；任何硬门失败保存已完成结果、停止本轮、交付停止报告，不自行诊断、放宽或恢复。登记提交号先于任何模型调用。

- 选取规则（零前向，采样前冻结）：对每段源历史，按存档续写序号升序，取第一条同时满足以下条件者为 R1_nat：末行解析为 cand₁；第一句（冻结句规则，名字保护）命中让步规则；全文不含 own₂、cand₂ 的任何形式（原样、归一化、别名）；未截断、未循环。无合格者则该历史退出（报告数）。
- 构造：段 2 = m₅ ＋ R1_nat（存档词元原样，含其末行）；段 1、3、4 与实验六相同。开场跨度 = R1_nat 的第一句词元跨度（登记哈希；报长度分布；不设上限）。另记 R1_nat 正文内本版错配命中数（自然正文可能自带错配，可能独立诱发 R₂ 错误）。
- 条件：N_nat 与 O_nat（从助手头到结束禁读该第一句跨度），每历史各 4 条；门同 §2.4 原则（10 段空遮断首步门）。
- 登记量：O_nat − N_nat 的 Y1、Y2、Y3 与次要结局，两层判读；N_nat 的 Y3 作为"开场延续在自然前序下是否发生"的描述性检验；按源单元（F-D：前序让步为正确更新；S_T：前序让步为错误翻转）分层描述，不作推断。
- 判读：O_nat − N_nat 与 O−N 同向且 Y2 区间排除 0 → 机制在自然让步下复现；N_nat 的 Y3 < 0.5 → 开场延续是合成句特有，作为现象边界如实报告；Y3 高而 Y2 不降 → 自然 R1 的其他内容另有承载。
- 事先预期：N_nat 的 Y3 高；O_nat − N_nat 与 O−N 同向，幅度可能更小（自然 R1 更长、含更多可读取的内容）。

**3.3 E1X：跨作品目标（496 条）。**

- 为什么：目标与前序共享人物、关系、版本是第二处人工之处。若开场延续在不共享人物的目标上仍成立，机制就不是"同作品译者话题的延续"。
- 构造：前序沿实验六的 A、B 标准化 R1（让步开场对角色提示开场，正文与末行相同）；目标改为**不同作品**的既有作者题历史（X 设计 60 段中的一条：冻结 Q、原答、S 臂压力与候选 X）。分配规则：对源作品 w_i（9 部，按编号序），目标作品为 10 部作品编号序中的下一部（R-010 → R-001；R-009 可作目标）；目标历史取该作品序号最小、与源作品名字集合 N_w（own₁、cand₁ 全部形式）无交集且通过依赖规则（n₂、n₄）的作者题历史；无合格者顺延下一部作品。报告分配表；目标端独立单位仍为 9。
- 条件：A、B 各 62 段 × 4。读出标准集（关系三轴按目标作品的冻结目录）。
- 登记量：A−B 的 Y3、Y1、Y2 配对差，两层判读；与实验六同名量并列描述。
- 判读：Y3 差保留（≈0.9）而 Y1、Y2 差被限制在 ±0.025／±0.05 内 → 开场延续一般、末行错误需要同作品关系路径；Y3 与 Y2 差都保留 → 跨作品仍有关系替换路径（候选仍为译者职业者），E1′ 成为下一项；Y3 差消失 → 延续是桥接特有（与 L6、L7 冲突，须先查材料）。
- E1′（非译者职业的真实人物作候选，只改压力消息中的名字；需人物与作品无作者、译者、编者关系的核对）排第四轮。

**3.4 第三轮预算。** Bd 248（＋248）；NAT ≤ 496；E1X 496；诊断前向各 ≤ 20。交付 `internal7_Bd`、`internal7_NAT`、`internal7_E1X` 各自的 prereg、prep 与报告。
