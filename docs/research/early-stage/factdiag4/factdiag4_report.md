# 第四批：声明顺序、先答依赖与修复方式的实际表现

**实验A：把用户复述移到施压之后，改答率从2.9167%降到0.8333%。** 末尾减开头为−2.0833个百分点，95%作品重抽区间为[−3.7500，−0.4167]个百分点，方向支持顺序有影响，但点差未达到预设的至少降低3个百分点，也未出现至少升高3个百分点的反预测。末尾复述仍有4/480次改答；第三批助手侧自我重述前缀（A1）为0/480。这是同一组历史的跨批参照，未设置等价性门槛，不能据此宣布两者等效，更不能认定自生成机制。

**实验B：自我重述通常没有固守植入的虚构先答，却也没有在关键条件中恢复正确译者。** 在“虚构先答、用户推举相邻译者”的第三格，强层自我重述下真译者为0/28，相邻译者为27/28，虚构名为1/28；作品等权分别为0%、95.8333%、4.1667%。相邻译者比例的95%作品重抽区间为[0.8750, 1.0000]；身份结局均无缺失，零真译者事件的严格界不可判。这直接反对预设的恢复真译者至少60%的预测。用户推举真译者时，第二格强层两臂均全部答对，未显示自我重述带来额外纠错。第一格弱层保持相邻错误先答仅8.3333%，也未达到预设的50%。因此本批构造条件支持“很少固守虚构先答”，不支持“自我重述会脱离双方错误选项恢复知识一致答案”。

**实验C：三套前缀均未通过全部预注册经验要求，未触发方法选择。** 角色核对（B1）、不确定性核对（A_unc）、组合核对（A_comb）均压低原作者问题中的目标漂移，但正确纠正单元的自信错误坚持相对第三批无前缀分别增加35.4911、27.6042、25.5952个百分点。角色核对和组合核对的原作者问题旁支否认率分别为13.8671%、13.9683%，均高于7.2%目标；不确定性核对在正确纠正和弱层同角色施压中均未产生机器判定的带保留回答。组合核对的合法切换点差为−2.9167个百分点，经验达标，保守单侧下界为−11.2500个百分点，有限样本下尚未排除超过5个百分点的代价。三项自信错误坚持增量的95%作品重抽区间依次为[5.2827，67.8199]、[1.5625，54.6875]、[1.7820，51.1905]个百分点，这些结局均无缺失。以下保留完整结局向量、区间、缺失界与逐项严格状态；研究停止在报告。

以上结论使用冻结规则和原机器标签。独立复核由代理完成，非人工，不回改标签。作品等权决定经验验收，历史等权并列描述；两者出现差异时不替换预先选定的权重。

## 一、比较的对象与统计口径

开头复述（SR）和末尾复述（U_last）仅移动同一句用户提醒的位置。无前缀条件在数据中记为 `base`。三套新助手前缀分别要求核对候选角色、区分可核实与不可核实内容、或组合复述与核对步骤；比较对象是完整前缀，不能把结果归给其中某一句。原作者问题（R-S）检验是否被施压改答译者，同角色错误施压（S_T）检验是否采纳错误译者，正确纠正（F-D）检验是否接受真译者，合法改问（L）检验用户正式改问译者后是否正确切换。

所有比例先在每段历史的有效续写中计算，再按历史或作品平均，因此不一定等于表中合并事件数除以合并有效数。缺失两端界把未知结局分别放到不发生与发生的两端；它与按作品重抽2000次的95%区间回答不同问题。严格验收使用预先写定的保守单侧界；零事件、相关事件总数不超过2或重抽退化时，严格界不可用，不临时补二项区间。表内退化的[0,0]等描述区间不表示总体风险被严格证明为零。 除正文明确标注百分比或百分点外，表内率、差值、界与区间均采用比例单位；差值0.01等于1个百分点。

本批与第三批的比较保留同一历史配对，第三批无前缀和自我重述续写均未重新生成。正确纠正只使用39段及旧对应39段；正确缩写误纳的三段仅在[步骤0](factdiag4_step0.md)中描述。步骤0的补查不改变本批采用的原机器标签。

## 三、实验B：放弃虚构先答后，答案主要转向用户候选

三个答案身份分别是真译者（T）、相邻译者（d_T）和虚构名（F_w）。第一格（B-1）植入相邻译者、用户推举真译者；第二格（B-2）植入虚构名、用户推举真译者；第三格（B-3）植入虚构名、用户推举相邻译者。前两格接受候选与回答真译者同义，第三格的先答、候选与正确答案互不相同，只有恢复真译者才对应预设纠错预测。

材料检查后实际保留13段基底、26个构造变体。强层为7段历史、3部作品，弱层为6段历史、2部作品；每格每臂分别为28和24条续写。强层实际分母不使用原计划18段。两类变体各保留：R-002为2段、R-004为4段、R-007为1段、R-005与R-006各3段。强弱层按既有知识表现固定，来自不同作品，不能把任何组间差异唯一归因于知识。
