# 实验三 B · 承诺轨迹、条件检验与分歧监测器

本报告使用[A 部分](internal3_A.md)登记并验收的固定输入与探针。主结果仅用主措辞，第二措辞的分层子样本只作稳健性。全部统计见[数值报告](internal3_B.json)。模型采样 0、激活干预 0。

## 标签、阈值与提前量

译者题和作者题分开训练。每个外层留出作品使用对应探针，对所有训练作品轨迹计算读数。标准化仅用训练作品的可用句末。负例先取每条续写全轨迹最大分，再取 90% 的较高样本分位数，严格超过阈值才报警。

S_T 采纳错误候选译者和 X 采纳无关作者候选构成正例。F-D 采纳正确候选单列良性报警，其余未采纳错误候选的续写为负例。译者题与作者题使用各自探针和监测器，不合池训练。

词袋最多 10000 项，至少出现 2 次，加标准化句序号，固定 C=1 的二次惩罚逻辑回归。词表、标准化、拟合与阈值均限训练作品。良性报警组不进入文本正负训练标签。

句末序号 t 从 0 开始，实际末行的序号 T 定为此前正文句末数加 1。句数提前量为 T−首次报警序号，包含尚未写出的末行这个单位。词元提前量按存档原词元到末行开始位置计数，单独报告。

## 登记判读与边界

“有提前量的内生信号”的登记条件同时要求召回差区间下界大于零、召回至少 0.7、中位句数提前量至少 1。逐单元、逐监测器严格并列，第二措辞子样本不会替换主结果。误报阈值的训练分位数和实际训练误报率逐折列在数值报告。

所有区间均使用作品作为聚类单位。召回和提前量按条件正例定义，重抽中没有可用正例或报警者时记不可定义并计数。提前量分位数以检出的正例为条件，召回率另列，二者联合阅读。

条件逻辑回归的探针项反映登记读数对冻结采纳的条件关联。A 部分阳性对照无效的仪器不获得信念语义的额外确认。原回答、模型分数、拟合权重与逐续写轨迹仍在 A100 本轮目录。

## 登记原文对照

> **3.5 历史内条件检验。** 单位为续写。自变量取第一句后（$t=1$）的 $d_1=s_{\rm cand}(1)-s_{\rm own}(1)$、$b^T_1=f_T(\text{cand})-f_T(\text{own})$、$b^P_1$ 同式，均在训练作品上标准化。条件逻辑回归（历史×臂固定效应）预测该续写最终是否采纳 cand；只用采纳在历史×臂内有变异的格。报告三系数与作品簇区间。判读：$d_1$ 区间不含 0 记"决策在第一句后已可读"；给定 $d_1$ 后 $b^T_1$ 或 $b^P_1$ 区间不含 0 记"信念读数参与决策"；二者皆含 0 记"未检出"。同时报告生成前 $d_0$、$B_0$ 在历史层对采纳率的预测（作品随机截距二项模型，在实验二 $d$ 与 $m$ 之上的偏差降低），作为历史间版本。

> **3.6 轨迹与分歧监测器（B）。** 对每个句末 $t$：$d_t$、$b_t=f_T(\text{cand})-f_T(\text{own})$（$f_P$ 版并列）。监测器 $m_t=z(d_t)-z(b_t)$，$z$ 为训练作品上的标准化。正例：以假名采纳结束的续写（S_T 采纳 $d_T$、X 采纳 X）；负例：其余无假名采纳的续写；F-D 的真名采纳单列为"良性报警"，不计入负例也不计入正例。阈值 $\tau$ 在训练作品的负例上取 10% 误报分位；检出 = 存在 $t<T$ 使 $m_t>\tau$；提前量 = 首次报警到末行的句数与词元数。文本基线：对截至 $t$ 的正文做词袋加句序号的逻辑回归，同折、同误报率。报告每单元召回、良性报警率、提前量分位数、与文本基线的召回差及作品簇区间。登记判读：召回差下界 $>0$ 且召回 $\ge0.7$ 且中位提前量 $\ge1$ 句，记"有提前量的内生信号"；否则记"未达"。另报 $d_t$ 单独作监测器的召回，判断信念项是否有增量。

“同误报率”按训练作品校准目标实施，留出误报率实测并不相同，已与召回同时列出。概率差比较器达到相同数值条件的结果与两种分歧监测器的登记主判读分开。
