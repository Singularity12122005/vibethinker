# 第六批 G 主报告：跨结构预测优势与机制边界

本批最强结论来自三个层面的结果。第一，文献作者问题中的最终改答不仅出现在真实相邻候选上：强施压可以使无关真实译者或虚构姓名获得编造的本版关系，即使回答仍保留正确原作者；通用审慎前缀又能把本版译者目标错误降低30个百分点。第二，可计算题能从两种错误候选都未给出正确值的历史中恢复答案，但恢复在无重述前缀时已经发生，原定的前缀增益与部分干净能力外推预测失败。第三，在完全冻结的共同变量和机器标签上，双分量模型的文献域参数在至少两个新结构上取得明确的相对联合预测优势，满足原预注册判据。

这三条不能合并成“已识别两种内部算法”。固定模型的相对优势伴随严重的绝对预测偏差，留一结构时存在反转，角色和命题标签的可靠性较弱，电影读数还存在冻结口径差异。已有证据支持的是具体行为、具体干预作用和具体预测比较；进一步声称普适查询变换、真实相邻关系必要、重述前缀独有的恢复作用，或内部处理方式已被识别，均受到本批实证反例或明确证据缺口阻挡。

## 1. 判定对象、口径与完成范围

项目等权决定判定，历史等权并列。通常先平均续写、再平均历史、最后平均项目；电影版本以方向等权，重抽以同名电影配对为簇。区间使用既有2000次项目重抽。事件的缺失两端界与重抽区间是两种不同信息：前者把未知全部当成非事件或事件，后者反映项目重抽变化。缺失不计零，零事件不作验证；筛查前提不满足优先记“未检验”。经验数值是否符合与严格状态分开，不追加置信区间显著性门槛。
