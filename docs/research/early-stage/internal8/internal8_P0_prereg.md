# 第二阶段第零步预注册

本次执行以已提交的[研究计划 v1.3](../../sycophancy-phase2-write-component-plan.md)（d2bf203）中 P2-0 全部定义、材料、顺序与停止规则为准。先登记后计算。当前阶段采样为零。后续行为阶段须按原方案另行评阅。

先以脚本前序五条件实验的 N、O 两臂各 248 条验收。第一折作品 001、003、004、006、008，第二折 002、005、007、010。按冻结的让步规则和首句作者承诺标签构造让步、直接、混合、其他四类。混合不参与建表计数，不进两类排序。使用实际生成词元编号，每份词表只取训练作品。纯度至少 0.9，目标类别至少 3 条。歧义、未见或长度不足的留出记录得中间分，保留在相应分母。合并折外结果，两类覆盖分别至少 0.80 且排序面积至少 0.90；覆盖指本类被本类词表正确命中。自然前序 N、O 两臂各 208 条只接受所属作品的折外词表，不参与建表、选量或过门。

单步失败则按 v1.3 依同一顺序检查二词元词表；首词元最低频数 3，包含共享首词元。两步量的词表验收也可在存档上零前向完成；概率读出按计划在第二查询禁读源开场。选定量的行为效度为按历史配对的 N 减 O 的读数差作品簇 95% 区间下界大于零，且与同历史让步率差的平均秩相关为正。依次使用单步、备用两步，达不到两道门的量不得用于拟合。作品簇重抽 2000 次，历史等权。自然集单列。原始回答和逐历史张量留在计算服务器。

过门后执行原计划的双向恒等检查、助手头全部查询位置归因、折内选头与选秩、折外读数确认及语义对照。合成写入分解只取助手头末位置，按同层所选头组报告。全词表分布差只在精确操作后报告。无关句、异词同义句、同词异用句固定使用 v1.3 P2-0 的三个示例原句。层间差异按第 1 节第 1 项解释为上游变化抵达，行为贡献以干预读数判定。停止时如实报告已得分母、统计量与未执行项。
