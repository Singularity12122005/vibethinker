# 书目 E1 与语义开发集末行探索：分析前计划

本轮按用户指示，先做标签齐全的书目 E1。语义 768 条已核对完整，但正文标签尚未完成，只将末行正确性作为探索性次要结局。本文在计算任何控制策略的实际表现之前写定，不使用新题留出内容。

## 书目 E1

输入为同一（来源历史，重复号）的原生 N、全跨度遮断 O、整组移除 L，各 248 条。N/O 从 G1 正式存档读取，L 从 P1a 正式存档筛选，依条件名称和键配对，不按文件顺序配对。使用已有关系错署、末行和当前关系作答标签，缺失标签报错，不补标。

对 N→O、N→L、O→L 分别报告 G、D、UU、RR。关系错署的 N→L 应复现 41、10、36、161。无关系错署只解释为该事件未发生，当前关系答对独立报告。

选择器只用两条分支已有首句字段中实际存在者，字段在读取模式时确认后一次固定，对三组比较统一使用，不按收益改特征。规则最多两个条件合取，按训练集净收益选择，同分优先简单规则。九作品六训三验共84折，同一回答的28次验证决策先平均。报告折外期望收益、损伤、残余错误和诊断性理想选择。始终原生／始终操作为简单基线。不对稀少作品上的开发表现签发通用结论。

## 语义 768 条

### 输入、结局与范围

读取完整合并的64历史×三臂×四重复，逐键校验，五条长度触顶保留。评价主要使用最后明确答案是否等于题面解释器的已核定值；自然结束但机器无法解析的末行列出供逐条核对。未完成／无法判定按未成功作答计损失1，另报告其数量与处理敏感性。这个结局不表示正文没有出现过错误断言。

首个事实承诺事件目前没有合格位置标签。为避免把完整答案伪装成早期信号，本轮分为两个明确时点。

1. 首句阶段只复用已有句界提取，使用可由该前缀判断的措辞字段及两臂措辞差异。它称为早期措辞策略，不称为事实承诺识别。若字段无法提取，保留缺失并使用训练先验。
2. 完整草稿阶段用末行的规范化取值，计算原生采纳用户候选次数、原生四次回答不同取值数、最大一致票数，以及四组原生—操作末行分歧次数。这是生成完草稿后的核验调度，成本计完整生成，不能据此声称早期拦截。

候选从实际用户消息提取，真值只用于评价。正文真值、资格侧别、题号、规则族、全遮断的对错均不作触发特征。侧别只在评分后分层显示。

### 比较与预算

统一全体排序选择16段历史，历史内四重复共享选择；并列实际涉及的不同题目／解释器核验次数。未选历史不会因同题已核验而自动计为修复。随机触发期望损失解析计算。理想触发按四次原生平均损失排序，标为知道结局的上限。

完整草稿的低复杂度学习策略依次为原生候选计数（加不可解析数）、再加原生不同取值数、再分别加 N/O 或 N/L 分歧。所有策略同样最多两个条件合取。另列无训练基线：原生重复不一致优先、候选采纳次数优先、原生与操作分歧次数优先。最后两种属于诊断性的简单分数，不能按结果选择最好者当预登记主策略。

所有学习策略按题留一交叉拟合，不读取该题任何历史的评价标签。同分预算选择对边界同分组做均匀随机的解析期望，避免以题号隐式择优。直接核验全部不同题目另报成本。本轮不试其他预算找胜出位置。

### 不确定性与判读

先报告完整计数和按题的损失贡献。固定交叉拟合预测上的按题联合重抽2000次，保留该题所有历史、臂和重复，重算16/64比例的预算选择，报告描述性95%区间；该区间没有覆盖模型重训的全部不确定性，不能作为确认性检验。无训练分数不涉及拟合，但仍限于开发分布。若差异小于区间或不同基线排序不稳定，直接记未见稳定增量。确认需要冻结策略后在未读的新题上评价。

由于正文主结局和承诺识别器缺失，本轮不会据末行探索宣布正式 E3 通过或决定真实反馈有效。未来正式结果需回到已登记正文指标，并满足前缀测量验证。

输出配对表、策略收益及损伤、残余损失、分侧结果、实际执行对象数、生成条数及词元数。早期预览若缺少可精确还原的词元截点，只报告文本长度，不用字符数冒充词元数。计划、脚本和结果报告分别保存，不覆盖原始实验数据。
