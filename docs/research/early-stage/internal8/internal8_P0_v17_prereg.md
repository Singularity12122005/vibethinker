# 第零步写入分量执行登记

执行方案为 `aa9dac1` 的第零步。此次为零采样教师强制、读取遮断、反向归因及定稿内的补回读数。材料选择来自 `4db4a87` 的未舍入表。主排序取温度 0.7 的概率预计下降，正值表示遮断使概率下降。原生、遮断都从助手头第一个查询开始区分。实际漏识别用逐续写事件确定；R-008 无漏识别者为原始历史编号 2（按 0 起编号），附七括号中的编号不用于筛选。

双向恒等检查在部分编辑的结论之前进行。诊断材料在看编辑结果之前固定为每一训练折按完整历史键升序的第一段入选历史，取其原生和遮断各第 0 条冻结续写，覆盖全部已存词元。各比较用相同的前缀切分、助手头和后续分块；比较每查询、每层残差与下一词元分布，不续写。先求两次原生的数值地板，再用原式确定门限。全头移除对照独立的原遮断实现，全头补回对照独立的原生实现。若触门，停在首次失败处，保留位置及覆盖数。

两折训练为 18、31 段，漏识别敏感性为 16、28 段。首词元集合按冻结表；原生与全遮断的第一步归因差在同一头当时的状态上计算，助手头三处求和。头前缀按每一整数长度求累计，确认八成最短前缀时不假定单调。分母分别为全头遮断与所选头完整补回。其余判据、条件与阶段边界依方案。
