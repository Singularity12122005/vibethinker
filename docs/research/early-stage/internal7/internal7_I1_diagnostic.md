## 修复建议与边界

现实现已在32位浮点中先逆旋转、再重旋转，最后恢复缓存精度；因此只重复提出“改用32位”不足以回应本次问题。建议把两次线性变换先作代数组合，避免形成容易发生相消误差的中间反旋转向量：

```text
den = cd² + sd²
a = (cr·cd + sr·sd) / den
b = (sr·cd − cr·sd) / den
k_new = a·k + b·rotate_half(k)
```

其中`cd,sd`为供体位置的实际余弦、正弦，`cr,sr`为接收方。该式在实数运算中与原定义等价；同位时统一公式给出`a=1,b=0`，不需要为自替换写跳过分支。合并式尚未实现或运行，不能称已修复；同位通过也不能单独证明跨位置变换正确或取得科学效果。
