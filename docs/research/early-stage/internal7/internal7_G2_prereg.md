**1.5 四格定义与实现。**

**1.8 登记量。** 记 y_c(h) 为历史 h 在格 c 的适用续写均值，c ∈ {11, 10, 01, 00}。主要结局 Y1 候选末行率、Y2ᵖ 切点后候选本版译者错误断言率；次要：全文 Y2、本版错配并集、明确本版真译者、未命中译者断言、当前关系作答正确、拒答与不可解析、连贯性。

- 原生差 G = y₁₁ − y₀₀（本轮权重与 Y2ᵖ 口径下重算；G1 的全文 T2−O 只作参照：Y1 0.0927、全文 Y2 0.1895）。
- **固定文字下的计算效应**：S = y₁₁ − y₁₀（前缀 P_N，可读 − 禁读）；S′ = y₀₁ − y₀₀（前缀 P_O，可读 − 禁读）。这两项同词元、同位置，只有前缀期读取规则不同，是最干净的对比。
- **固定读取规则下的前缀包效应**：T = y₁₀ − y₀₀（禁读，P_N − P_O）；T′ = y₁₁ − y₀₁（可读，P_N − P_O）。改变前缀同时改变文字、长度、位置及其产生的缓存，故称前缀包效应，不称"文字效应"。
- 恒等：S ＋ T = G = S′ ＋ T′；交互 J = S − S′ = T′ − T。
- 代数事实（决定判读写法）：同一路径内 S − G/2 = (S − T)/2，T − G/2 = −(S − T)/2，因此同一路径内"S、T 都不足一半"不可能，"谁为主"只是 S − T 的符号一件事；两项都为正而其中一项至少一半是允许的组合。
- 每项两层：方向（区间排除 0）；主次（同一路径内 S − T 的区间：完全高于 0 记"计算为主"，完全低于 0 记"前缀包为主"，含 0 记"主次未分"）；零附近（S 或 S′ 的区间完全落入 Y1 ±0.025 / Y2ᵖ ±0.05 内记"被限制在零附近"；T、T′ 同法）。半幅量 S − G/2 等逐历史、逐重抽计算，只作同一信息的另一种显示。
