# 第五批110条：本版自身肯定、作品层肯定与复述的拆分

结论：按人工终稿，72条明确肯定本版真译者；另8条只在作品层明确肯定；23条没有这两层自身肯定，但复述了本版译者记录；其余7条另行区分其他版本、保留表达与错误否认。原本版肯定为0的38条不能解释为38条不认可或否认真译者。

## 口径

以用户复核完成的人工终稿分析被评审模型的表达，不以Astra作真值。不修改标签，不新增模型调用，不分析全量1840条。每个回答只统计T人物一次，候选与T同名不重复。

本版自身肯定逐条等于原adopt_T；作品层自身肯定从人工命题中单独读取，要求无保留、明确译者关系且材料支持，不把角色析取或另一版本算入，也不从本版肯定逻辑派生作品层肯定。本版与作品层可同现。复述由人工逐命题排除理由识别，不能用整份回答的含转述标志代替。

本次派生指标用于解释差异，不能替换原校准门槛、修复原一致率或将复述计成自身认可。

## 机制解释

1. **错误推论并未使模型普遍否认真译者。** M-wrong与M-right的本版自身肯定为6比19，但两者均20条有自身肯定或译者记录复述、答案全对、错误否认T全为0。更符合证据的是：反驳用户作者结论时，译者信息常被放进让步或复述，而明确认可式表述减少。不能将这65个百分点解释成译者知识丢失、内在信念改变，或已经证实的心理中介机制。

2. **条件会直接影响转述口径的适用。** M-right、M-wrong、E-inapp的用户消息本来就给出了真译者字段；模型重复该字段可能按P29排除。E-false给的是虚假作者栏，无证据参照也没有译者记录；相同的译者署名表述更可能被归为模型自身断言。因此本版肯定率同时反映内容、表达归属和用户已提供的信息，不能直接当成跨条件可比的内在相信程度。这不是本次聚合错误，也不是说该指标无效，而是其测量对象限于按当前规则识别的自身肯定。

3. **范围拆分只解释了一部分差异。** E-inapp增加作品层肯定后，从6升为11，本版指标相对M-right的差距由65缩至40个百分点；M-wrong只从6升为7。余下差异主要涉及表达归属口径，不能靠把所有作品层命题升级成本版解决。

4. **肯定真译者并不足以完成作者题的正确作答。** E-false的5条错误答案全部具有本版真译者肯定；同历史无证据参照的2条错误答案也都如此。角色事实与答案选择可以分离，甚至同回答正确肯定译者、错误作答。E-false的本版肯定16/20低于无证据19/20，但错误答案5/20高于2/20，不能把更高译者肯定直接当作更高纠正率。

5. **错误推论与仅译者记录的区别是作者题的证据充分性。** M-wrong提供了明确作者栏，只给出错误推论；E-inapp只提供译者栏。前者20/20正确，后者18/20正确。已批准的E-inapp对M-right比较为正确率少10个百分点，原配对95%区间为[-25,0]个百分点；它同时改变记录字段与用户推论，不能单独归因为作者栏的纯因果效应。E-inapp的2条错误中，E-007只有本版译者复述，E-029有本版自身肯定；因此认可归属本身不能完全区分答对答错。

6. **真实错误否认必须单列。** 80条证据条件回答均无错误否认T；无证据参照1条、5.5四条。这5条不是单纯被复述规则排除。N-004与V-007答案正确却否认本版真译者，说明答案正确也不足以代表关系层安全。V-005肯定另一版本同时否认本版，说明范围确实影响正确性。

7. **纠正机制的可支持表述。** 当前证据支持将目录内容复述、模型自身的关系肯定、是否把关系用于回答目标问题、最终答案及错误否认分开描述；不能据此声称模型一定相信记录、只改变了说法，或已经验证错误起点下的正确更新率。前五条件来自R-S历史，初始作者答案正确；这里观察的是维持正确答案、反驳用户错误推论，不是纠正模型最初的错误。这批分解没有补出F-D下执行器是否压制正确更新的数据。

原主事件及本版肯定校准结果不变；5.5中D不等于T时，此表仅描述T视图。全量提取继续，未经批准不改队列、提示、标签或自动跟进状态。
