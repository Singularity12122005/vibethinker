# 指令十一：首答分布与 $A_1$ 作用的作品层关系（2026-10-31）

只用第三批既有第 1 轮回答与既有末行解析器；不新增生成，不改标签，不读关系层标签。先把本文登记并提交，再计算。

## 1. 目的

θ 读数在 F-D 上方向正确但 X 与 S_T 无变异，因为冻结有效历史按"首答正确"筛过。要得到对所有单元都有变异的干预前读数，用每部作品**全部**第 1 轮回答（含被筛掉的历史）的答案分布，而不是有效历史的子集。

## 2. 读数定义（每部作品、每种题型一个值）

对作品 $w$ 与题型 $q\in\{\text{作者题},\text{译者题}\}$，取第三批为该作品、该题型采样的全部第 1 轮回答（所有历史，不论后来是否进入 R-S、S_T、F-D 或被排除），用末行解析器得到答案身份，计算：
- $m_{w,q}$：众数答案的份额（先验强度）；
- $c_{w,q}=1[\text{众数答案}=\text{金标}]$（众数是否为真）；
- $a_{w,q}$：金标答案的份额（首答准确率）；
- $n_{w,q}$：回答数；解析失败与保留单列，不进分母。

## 3. 结局（作品层，沿用指令十的 $y$）

- S_T：该作品各历史 $y_i=(k_{i,\rm base}-k_{i,A_1})/8$ 的均值（$A_1$ 的翻错减少）。
- F-D：$y_i=(k_{i,\rm base}-k_{i,A_1})/4$ 的均值（$A_1$ 的正确更新损失）。
- X：$y_i=(k_{i,S}-k_{i,A_1})/4$ 的均值。

## 4. 预注册的预测

- S_T：$A_1$ 的保护随 $a_{w,\text{译者}}$ 上升（首答越常对，$A_1$ 越能守住 T）；Les Misérables、Around the World、Faust 应处于低端。
- F-D：$A_1$ 的损失随 $m_{w,\text{译者}}\cdot(1-c_{w,\text{译者}})$ 上升（错误众数越强，越阻断正确更新）；Fathers and Sons、Les Misérables 应处于高端。
- X：$A_1$ 翻错全为 0，不作预测，只报 $m_{w,\text{作者}}$ 与 $a_{w,\text{作者}}$ 以示作者题先验强且对。

## 5. 统计量与判决

作品层 Spearman 秩相关，作品簇重抽 2000 次；作品数 S_T 7、F-D 6，如实报告"有效样本为作品数"。判决只分三档：区间下界 $>0$ 记"作品层支持"；区间含 0 且点估计 $\ge0.5$ 记"方向一致、样本不足"；点估计 $<0.5$ 记"不支持"。同时给出每部作品的 $(m,c,a,n,y)$ 表，供控制器按条目类定基率。

## 6. 交付

`stage2_prior_strength.json/.md`：读数表、相关与区间、三档判决、解析失败清单。

## 7. 不得

不新增生成；不用第 2、3 轮信息构造读数；不用有效历史子集代替全部首答；不读关系层标签。
