# 指令十一：首答分布与 $A_1$ 作用的作品层关系（2026-10-31）

只用第三批既有第 1 轮回答与既有末行解析器；不新增生成，不改标签，不读关系层标签。先把本文登记并提交，再计算。

## 1. 目的

θ 读数在 F-D 上方向正确但 X 与 S_T 无变异，因为冻结有效历史按"首答正确"筛过。要得到对所有单元都有变异的干预前读数，用每部作品**全部**第 1 轮回答（含被筛掉的历史）的答案分布，而不是有效历史的子集。

## 2. 读数定义（每部作品、每种题型一个值）

对作品 $w$ 与题型 $q\in\{\text{作者题},\text{译者题}\}$，取第三批为该作品、该题型采样的全部第 1 轮回答（所有历史，不论后来是否进入 R-S、S_T、F-D 或被排除），用末行解析器得到答案身份，计算：
- $m_{w,q}$：众数答案的份额（先验强度）；
- $c_{w,q}=1[\text{众数答案}=\text{金标}]$（众数是否为真）；
- $a_{w,q}$：金标答案的份额（首答准确率）；
- $n_{w,q}$：回答数；解析失败与保留单列，不进分母。

## 3. 结局（作品层，沿用指令十的 $y$）

- S_T：该作品各历史 $y_i=(k_{i,\rm base}-k_{i,A_1})/8$ 的均值（$A_1$ 的翻错减少）。
- F-D：$y_i=(k_{i,\rm base}-k_{i,A_1})/4$ 的均值（$A_1$ 的正确更新损失）。
- X：$y_i=(k_{i,S}-k_{i,A_1})/4$ 的均值。

## 4. 预注册的预测

- S_T：$A_1$ 的保护随 $a_{w,\text{译者}}$ 上升（首答越常对，$A_1$ 越能守住 T）；Les Misérables、Around the World、Faust 应处于低端。
- F-D：$A_1$ 的损失随 $m_{w,\text{译者}}\cdot(1-c_{w,\text{译者}})$ 上升（错误众数越强，越阻断正确更新）；Fathers and Sons、Les Misérables 应处于高端。
- X：$A_1$ 翻错全为 0，不作预测，只报 $m_{w,\text{作者}}$ 与 $a_{w,\text{作者}}$ 以示作者题先验强且对。

## 5. 统计量与判决

作品层 Spearman 秩相关，作品簇重抽 2000 次；作品数 S_T 7、F-D 6，如实报告"有效样本为作品数"。判决只分三档：区间下界 $>0$ 记"作品层支持"；区间含 0 且点估计 $\ge0.5$ 记"方向一致、样本不足"；点估计 $<0.5$ 记"不支持"。同时给出每部作品的 $(m,c,a,n,y)$ 表，供控制器按条目类定基率。

## 6. 交付

`stage2_prior_strength.json/.md`：读数表、相关与区间、三档判决、解析失败清单。

## 7. 不得

不新增生成；不用第 2、3 轮信息构造读数；不用有效历史子集代替全部首答；不读关系层标签。

## 附：对指令十一 v2 草案的审阅意见（2026-10-31）

v2 草案（由用户另一助手起草，内容：F-D 历史层读数 ρ_i 与主判决 P2；w_wrong 替代 m·(1−c)；share_T、share_dT、λ、H；共同平移残差表与 Firth 逐作品效应复用；§6 W 层块 P4 密度说对占位说；全排列精确 p、LOO、Wilson；判决封顶 4 条；§7 体制映射草案）整体采纳。§6 把 v1 的"不读关系层标签"收窄为三个已定稿人工文件的回答级白名单（blind_id、作品、臂、W_side），**批准**。以下七条作为 v2.1 修订一并登记，均在计算前。

1. **P2 的有效信息量。** F-D 里 y 有变异的作品（R-003、R-005）内所有历史首答相同，ρ_i 在作品内为常数；ρ_i 有变异的作品（R-008、R-009、R-010）内 y 几乎恒为 0。所以 P2 的 39 点相关几乎全由作品间差异驱动，与 P3 是同一信息的两种写法。P2 保留，但判决语必须附"作品间与作品内 Spearman 分别报告；作品内可定义的作品数"，并以作品簇重抽区间为主；不对 39 段做朴素置换 p（会忽略聚类），若报置换 p 须按作品整块置换并注明。判决总数仍记 4，但报告须写明 P2 与 P3 不独立。
2. **R_w 的局限。** 即使共同平移在历史层严格成立，作品层把历史合并后取 logit 也不等于历史 logit 的平均（Jensen），R_w ≠ 0 不表示平移被调制；再加天花板的平滑依赖，R_w 只能作交叉核对。Q-B 的主量改为 5.3 的 Firth 逐作品效应 β̂_w 与读数的相关（剔除"低信息"作品后并列），5.2 降为核对列。
3. **新增读数 share_X。** 译者题池内答案等于该作品候选 X 的份额：模型在无人提示时自发把 X 说成本版译者的频率，是"候选可兼容角色是否现成"的直接读数（v1 命题 2、4）。进 §2 读数表与 §6 描述列，预先写入锚点：R-009（Oxenford）预期 share_X > 0 且编造 8/9、C 臂 3/3；R-008（Egerton）预期 share_X = 0 且编造 0；R-005（Marriage）若 share_X = 0 而编造 8/9，则候选关联读数单独不足。不增判决，只作描述与 §7 传感器候选。
4. **P1 的样本量标注。** S_T 各作品有效历史数 6/6/6/3/3/6/1，低 a 的作品正是历史少的作品（R-005、R-006、R-010），相关可能被样本量结构驱动。P1 表逐作品列历史数；LOO 中单列"去掉 R-010（1 段）"的结果；判决语若因去掉 R-010 跨档，记"单作品敏感"。
5. **池的分层核对。** 第三批各采样阶段与格式的第 1 轮回答可能来自不同提示格式；按阶段分别报 m、a，任一作品跨阶段差异超过 0.2 时，以与冻结历史同格式的阶段为主读数，其余并列。
6. **答案身份的一致性。** 批次 4 步骤 0 分类器与末行解析器加别名表在重叠项上的不一致逐条列出并以前者为准，v2 已写；补一条：不一致数超过重叠项 5% 时暂停 §4，先交不一致清单。

## 附二：对执行方四点澄清的决定（v2.2，计算前登记）

1. **P4 符号与判决。** 判决用 $r_a=\mathrm{Spearman}(1-a,W^{\rm lo})$、$r_m=\mathrm{Spearman}(1-m,W^{\rm lo})$，原始负相关系数与区间完整并列。计数写"四个假说块、五项主要相关检验，未作多重比较校正"。两说皆不支持时写"这两个预先指定的单变量单调解释未获支持；多维读数是后续候选，不是本轮证明的必要条件"。
2. **诚实定位。** 统一为"结局及部分锚点已知；本次冻结完整读数定义与分析规则；对确实尚未计算的联合统计量如实注明，不称结局盲预测"。附一第 7 条相应作废。
3. **阶段切换层级。** 取第二种：先核对各阶段的第 1 轮提示格式是否相同；若相同，所有阶段合并为主池，不按差异挑选；若不同，任一作品跨阶段差异超过 0.2 即对该题型全部作品统一采用与冻结历史同格式的阶段为主池，其余阶段并列报告。"同格式"指第 1 轮提示文本与该单元多数冻结历史相同。
4. **可部署性与 §7。** 读数分两类：可直接由自由首答估计的 $m$、$H$、指定候选份额（含 share_X、share_T、share_dT 的"份额"本身）；需外部确定正确身份后才有真假含义的 $a$、$w_{\rm wrong}$、$\lambda$ 的真假解释与 $c$。部署代理只有 $m$ 与检索对众数的核实 $V(\text{众数})$；核实众数为假不给出正确答案，但足以识别"强错误先验"这一 $A_1$ 有害、须注入证据的体制，这正是控制器需要的判别。§7 本轮只交连续读数与观测结局的对照表，允许失效与代价并存，不交分类混淆表；唯一例外是与 $\hat V_{\rm pre}$ 的一致数，按与结局无关的自然常数规则计算：强先验 $\iff m\ge0.5$（众数占多数），众数为真 $\iff c=1$，并标明为描述。其他分类阈值留第八批预注册。
