## 2. N1(a) 组差进入曲线

**2.1 末行结局。** 每条续写末行按身份解析归为 own / cand / 其他 三类；报每单元每臂三类计数。自答保留 $r_c(T_c)=\mathbb 1[\text{own}]$，采纳 $=\mathbb 1[\text{cand}]$，二者之和可小于 1。

**2.2 二值曲线（主，标"正文概率读数＋行为终点"）。** 臂：译者题 A1 主、base 次、status 描述；作者题 S+A1 主、S 次。对 $t=0,1,\dots$：$r_c(t)=\mathbb 1[d_t(c)<0]$（$t<T_c$，实测）；$t\ge T_c$ 取 $r_c(T_c)$（行为终点，吸收）。历史内对续写平均，再历史等权。三个时间轴并列：
- **句序号轴**：共同窗口 $t\le t_{\max}=\max(\lceil q_{90}^{F\text{-}D}\rceil,\lceil q_{90}^{S_T}\rceil)$，$q_{90}$ 为各单元该臂续写长度 $T_c$ 的 90% 分位；报两单元长度分布（分位数）；窗口外只进附表。
- **归一化位置轴（并列主）**：以 $t/T_c$ 落入十分位，第 10 分位即终点。
- **固定集合版**：只取 $T_c\ge m$ 的续写（$m$ 为两单元合并的长度中位数），在 $t\le m$ 内画，避免短续写先被吸收伪造进入时刻。
- **真正终点**：$t\to\infty$（全部吸收）的值即 §2.1 的自答保留率，另列。

**2.3 组差。** $\mathrm{gap}^a(t)=\mathrm{ret}^{F\text{-}D,a}(t)-\mathrm{ret}^{S_T,a}(t)$（F-D 保留的是错误自答，S_T 保留的是正确自答；负值表示错误自答保留得更少）。区间：跨单元 10 部作品共用权重重抽 2000 次。三个版本：
- (i) 全样本；
- (ii) **共享三作品**（R-001、R-005、R-010）内的 gap(t)，并逐作品报符号，描述；
- (iii) **匹配子集**：以 $(d_i(O1),\alpha_i)$ 标准化后最近邻一对一匹配（不放回，卡钳 0.5 合并标准差；若实验二存档含 $m,H$ 则加入匹配变量并注明），F-D 对 S_T；报匹配对数与匹配后两组均值；对数 $<8$ 记"匹配不可行"。匹配后组差若消失，写"组差随起点与点名倾向消失"，不写"真值不进入"。
X 单列，不进 gap。

**2.4 连续曲线（次）。** $\bar d^{u,a}(t)$ 只汇总 $t<T_c$ 的实测值，报每个 $t$ 的有效续写数与历史数；不吸收、不填数。

**2.5 稳定保留时刻（描述，标"混合规则下"）。** 按 §2.2 的二值序列 $\tau_c=\min\{t:\ r_c(s)=1\ \forall s\in[t,T_c]\}$。只对末行为 own 的续写报 $T_c-\tau_c$（距终点句数）的 25/50/75 分位，按单元、臂；未过零比例不作为读数（它近似采纳率）。

**2.6 登记读数（描述性，不设三档）。** (i) $t^*=$ 句序号轴上首个使 $\mathrm{gap}^{A1}(t)$ 区间不含 0 的 $t$；若窗口内无，写"截至 $t_{\max}$ 未检出"；归一化轴报首个不含 0 的十分位。(ii) 真正终点的 gap 须等于 §2.1 两单元自答保留率之差（簿记核对，容差 $10^{-6}$）；$t_{\max}$ 处的 gap 与终点 gap 并列，只描述。(iii) base 臂同法。

## 3. N1(b) 起点分解回归（替代附三 §5(2) 作废的组内检验）

**3.1 变量。** $\alpha_i=d_i(C)$（点名中性读数分量；执行前逐历史核对 `neutral_prop` 等于 `prop`，不等者剔除并列出），$\Pi_i=d_i(O0)-\alpha_i$（证词增量分量）。因变量 $d_i(O)$，$O\in\{O1,O2,O3,O5,O8,O10\}$；O9 取历史均值只进描述。全部回归用 $\Delta^{(1)}$ 并行重算一遍（$\alpha,\Pi$ 亦按 $\Delta^{(1)}$ 定义）。

$$d_i(O)=a_O+c\,F_i+b_O\,\Pi_i+g\,\alpha_i+b_F\,\Pi_iF_i+g_F\,\alpha_iF_i+e_{iO},$$
$F_i=\mathbb 1[i\in F\text{-}D]$；$a_O,b_O$ 按开场；$g$ 共同。簇 = 作品（10 部，历史嵌套其中）；固定设计矩阵的残差野自助 2000 次，Rademacher 权重为主，Webb 六点权重并报；野自助始终保留全部作品，不作"不足三个作品"筛除（该规则只适用于作品簇重抽）。报 $g$、各 $b_O$、$g-b_O$、六开场等权平均 $g-\bar b$、$g_F,b_F$ 的点值与区间、$R^2$。

**3.4 两个完整模型的对照（描述，只写"不排除 / 排除"）。** 衰减型 $d(O)=\alpha+(1-r_O)\Pi$ 预测 $a_O=0,\ g=1,\ b_O=1-r_O$，其中
$$1-r_O=\frac{\overline{d(O)}-\bar\alpha}{\overline{d(O0)}-\bar\alpha}$$

**3.5 原登记数值保留。** $\mathrm{Spearman}(\alpha_i,\ d_i(O3)-d_i(O0))$ 原值保留，注明"受起点混杂，不作判读"。

**3.6 登记判读（仅主模型的 $g-\bar b$ 与 $g-b_{O3}$，§3.2 通过时）。**
