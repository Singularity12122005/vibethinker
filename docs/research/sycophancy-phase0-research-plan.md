# 研究计划（固定版）：社会压力下语言模型的知识使用失配与诊断式闭环控制

版本：2026-10-27 固定。来源：前四批结果（`docs/research/early-stage/factdiag{,2,3,4}`）、综合文档 `sycophancy-phase0-literature-synthesis.md` §9 至 §18、用户转来的"研究计划建议"。本文件取代此前所有关于主线的表述；后续只在本文件上做带日期的修订。第五批执行提示（v2.3）、第六批 G 与第七批的执行提示另立文件，须与本文件一致。

## 0. 主旨

研究冻结语言模型在冲突性用户反馈下，为什么会把已有事实用于错误的问题，或者在变得审慎后固守错误关联；检验能否通过候选辨别与任务限定响应诊断这种失配，并据此选择比较、重算、取证或明确保留不确定性，在减少错误迎合的同时保留正确更新。中心判断：**增强坚持不是方法；判断当前需要修复哪一种知识使用失配，才是。**

## 1. 已成立的四项结果（最强可写形式与边界）

**结果一：在锚定事实上，压力诱发的错误全部是任务失配，没有一例事实改写。** R-S 单元 480 条受压续写中，对原作者命题的否认为 0（C1：肯定 445、不可判 35、否认 0），而目标错误 200 条；批次1 的 140 条漂移全部仍提到原作者。再强一步的反例：弱事实（年份题 Y-020）会被持久改写（32/32）。所以主张限定在"锚定事实"。这排除了"谄媚 = 把正确事实改成错误事实"的统一解释，但尚未单独定位失配发生在问题解释、适用性判断还是最终选择。

**结果二：审慎式输入干预改变错误的结构，不保证整体真实性。** A1 把 R-S 目标错误从 200/480 降到 0/480，真实角色否认从 25 升到 56；39 段纠正单元的正确候选接受率从 0.974 降到 0.749；B1、A_unc、A_comb 与用户两种位置的复述给出同样的结构（目标错误 ≤0.04，否认 0.14 至 0.15，纠正接受 0.61 至 0.71）。六种不同的审慎开头在目标错误上的效果几乎无差别，这是本结果最强的部分。限定：F-D 测的是"正确候选是否被接受"，不是"有效证据是否被合理使用"；两者在第五批分开。

**结果三：审慎不等于重新检索真答案。** B-3 构造历史中两个在场候选都错，A1 后 28 次生成无一恢复真译者，27 次采用用户推动的相邻译者；B-1、B-2 表明模型不无条件维护被植入的先答（切回真译者 ≥0.92）。支持研究候选生成、候选辨别与最终选择的分离；不支持"内部不存在真答案信息"。

**结果四：干预损害具有可重复的实例结构。** 纠正固守与旁支否认在所有执行器下集中于同一组作品（R-003、R-005），S_T 的失败集中于版本知识弱的作品（R-005、R-006、R-010）；合法改问的代价同样集中（R-005 的正确切换 0.42 → 0.00）。已有的独立代理给出初步相关：A1 否认率与候选姓名对数概率的秩相关 −0.73，S_T 的 A1 损失与改问单元正确率的秩相关 −0.78，漂移风险与候选对数概率的秩相关 +0.43。尚未成立：某一个识别分数决定全部损害；任何内部读数都无法区分这些状态。

此前综合文档 §18 把逐作品表读成"单变量律"，现降为下文假设一：识别度尚未独立测得，逐作品表的大部分列是结局本身。

## 2. 科学问题与框架

设当前有效问题 q =（对象，关系，版本或时间限定），真实答案 g(q)；用户推动候选 d，d 可能是另一问题 q′ 的真实答案。三个必须分别测量的功能问题：

| 功能问题 | 要区分什么 | 主要实验 |
|---|---|---|
| 候选可用性 | 正确候选能否进入实际考虑范围 | 自由回答与候选给定对照（R1、R1′ 对 L） |
| 任务条件下的辨别 | 能否区分"与作品相关"与"满足当前关系、版本" | 候选识别、版本替换与措辞对照、关系查询 |
| 判断的行为使用 | 可用的判断是否真正控制受压回答 | 中性历史、受压历史、隔离核查与对话内比较 |

这是组织框架，不是预设的内部模块。"顺应式处理 / 审慎式处理"是这三个问题之间的一个候选计算模型：顺应式容纳用户候选并可借真实相邻关系偏离原任务；审慎式依赖模型自己的候选排序；排序若反映一般关联而非当前问题要求的精确关系，审慎就固化错误。它必须与连续候选偏置模型（干净偏好加压力与干预造成的位移）用相同的事前变量、预测相同的结局公平竞争。若简单模型足够，不算失败。

## 3. 三个核心假设

**假设一（相邻事实知识的双重作用）。** 独立测得的候选相邻角色识别度 r_adj 同时预测：无审慎时更容易形成容纳该候选的替代解释；有审慎时更少否认该候选的真实关系。先作预测关系检验（留出作品与新关系）；若要声称因果，再用少量受控的知识可访问性操纵。

**假设二（任务限定响应比自信更接近决策信息）。** 最顽固的错误可能是"一般关联强、当前限定使用不足"。保留三个读数 X(h) = (r_adj, m_target, z_scope)：候选相邻角色识别；当前问题下先答与用户候选的相对支持 m(q) = log P(x|q)/P(d|q)；限定响应 z_scope = m(q[e]) − m(q[e′])。必须与同一问题的措辞改写对照 z_wording = m(q[e]) − m(q̃[e])：要找的是对任务相关条件的系统响应，不是对任意文字变化的不稳定。两个附加前提：e′ 必须是真实存在且答案不同的版本；z_scope 只在模型能识别 e′ 的答案 d_T 的作品上可解释，否则"不翻转"可能只是不认识 e′，记为未定。成功判据不是 z_scope 等于正确率，而是在首答稳定性与候选支持相近时，它能否额外预测哪些历史适合保护、哪些需要核查，并在留出作品上增加策略收益。

**假设三（修复取决于失效环节）。**

| 诊断结果 | 候选修复 |
|---|---|
| 当前任务被替换，所需事实可用 | 重新明确当前有效任务 |
| 真答案难以自行生成，给定候选后可辨别 | 提供或比较候选 |
| 隔离核查正确，原对话中不能使用 | 改变核查结果进入最终决策的路径 |
| 当前候选无法可靠区分 | 获取适用于当前问题的证据 |
| 证据仍不足 | 明确未核实，不把不认识写成否定 |

最强目标是事前诊断预测哪类操作改善哪个状态。若统一的隔离比较已足够，就采用它；不为证明闭环而保留一个统一方法本可解决的问题。

## 4. 理论：哪些信息足以选择动作

**二动作子问题。** a ∈ {0, 1} 为不用、用 A1；S 为评价所需的完整状态；μ_a(S) = E[L(Y^a, S) | S]；b(S) = μ_1 − μ_0，b > 0 表示撤销 A1 有益。完整状态下 V_full = E[b_+]；只用读数 X 时 V_X = E[(E[b|X])_+]。信息损失
R_info(X) = ½ (E|b| − E|E[b|X]|)。
对具体规则 g(X)（g = 1 撤销）：V_full − E[g(X) b] = R_info(X) + E[m(X)_+ − g(X) m(X)]，m(X) = E[b|X]；第二项是规则损失。实验由此能回答：是读数没有区分需要相反动作的状态，还是读数有价值但规则没用好。此前写的 min{p·u, (1−p)·v} 是 R_info 在两点状态上的特例。

**两条边界。** 相近的观测分数不等于全部信息不可区分；固定提示不等于固定的实例行为——同一条提示可让模型内部按不同证据处理，所以二动作下界只对指定的动作集合与读数成立，不能推广为所有统一提示或所有后训练的极限。此前综合文档 §17.2 中"统一干预必然承担该损失"改为：在动作集合 {∅, A1} 内、读数为 X 时成立；四个前缀落在同一条权衡线上是经验陈述（n = 4）。

## 5. 第五批（诊断有没有读到与决策有关的信息）

执行提示 `sycophancy-phase0-batch5-execution-prompt.md` v2.3，结构不变，本计划要求的修订：
- 5.1 识别阶梯：干净候选识别 → 自然历史中性识别 → 自然历史受压选择；版本替换 V 在全部十部作品上做，并加同版本措辞改写对照；z3 只在 d_T 被识别的作品上解释。四候选含真答案只用于诊断能力；策略只用先答、用户候选、自生成或合法取得的候选；八次采样为筛查，只对改变主要分支的模糊格补精度。
- 5.2 修复：{∅, A1, 对话内比较, 隔离核查直接选择}。最有信息量的结果是"隔离识别正确而对话内比较仍错误"。离线隔离核查复用 R1′，同一组采样被多个历史共享，有效样本数按唯一三元组报告。若隔离识别失败，结论是"当前识别协议未恢复判断"，不是"证据是唯一可能的通道"。
- 5.3 证据：真实且适用、真实但支持另一关系或版本、表面适用但被篡改、只有权威声明；用户转述证据与独立取证分别命名；F-D 与 F-E 分开。核心问题是在候选名字同样出现时，模型是否只在证据支持当前任务结论时更新。
- 5.4 门控：G = E[g(h)·b(h)] 与两项分解；读数三层嵌套（首答稳定性 ⊂ 加候选支持 ⊂ 加自然历史与限定响应），每层报告 R_info(X) 与规则损失；0.12 为经验目标，不替代分解；关键损害集中于少数作品，所以简单规则先试，跨作品验证必做。
- 5.5 核实状态："已核实"指向当前任务中的具体命题；主看 P(答案错误 | 声明已核实) 与可声明已核实的覆盖率；评价完整回答，控制器附加的不确定注记不抵消正文已作出的错误否认。

## 6. 第六批 G（同一解释能否预测新结果）

材料与顺序按综合文档 §17.5（G0 → S0 → G1 → G2c → G2b → G2d → G2a）。成功标准收敛为两个：
1. 同一组诊断变量（候选关联、任务限定响应、可重算程度、首答稳定性、当前干预）能否预测新关系中的目标错误、旁支否认与纠正代价。统一量 M(q, q′) = P(Y = g(q′) | q, 用户推动 g(q′)) 与无社会证明对照的差 ΔM；M 只表示采用了替代问题的答案，是否重解释问题须结合任务与命题标签。
2. 连续偏置模型与共享处理方式模型公平竞争：相同事前变量、相同结局，简单模型也须预测旁支否认而不是当作噪声。两模式模型的可检验约束：同一历史在不同干预下的结局向量 p_a(h) = π_a(h)·p_1(h) + [1−π_a(h)]·p_2(h) 落在一条线段上；G0 用批次3、4 已有的 ∅ 与四个前缀在同一历史上的结局向量先做免费检验（按作品汇总以降低八次采样的噪声）。A0 检验保护是否需要具体事实或任务内容，不单独证明离散模式。
三个边界：版本任务分开自由回忆正确率与给定候选后的版本辨别；自然 F-D 不足时记未检验，不用零事件宣称无纠正代价；可计算任务的构造历史中，正确结果不得以完成结论的形式留在先答的推导里（构造先答只给结论，不给推导），"恢复缺席答案"与"不妨碍自然纠正"分别评价。

## 7. 第七批（闭环操作是否有额外价值）

控制对象是"下一次计算最应该解决什么问题"，不是"多坚持还是少坚持"。第一版是单个用户回合内的闭环：当前任务与候选 → 一次诊断 → {直接采用可靠的候选判断；在当前输入上重算；获取适用证据；明确未核实} → 观察 → 回答或停止。触发：只在用户消息含证据结构（社会证明、权威、引用资料）时诊断，无社会证明则空转（证据门槛律）；诊断前先判任务是否合法改变，改变则复述新问题（合法改问代价）。

在线控制器只装经第五批证明有决策增益的最小读数子集；完整诊断集合是研究工具。对照至少四个，同等信息与平均预算：最强统一前缀；固定隔离核查流程；相同平均预算的固定或随机取证；诊断式闭环。评价正确性、合理纠正、旁支事实、任务完成率（含 L 单元）与成本。若闭环只节约计算，主张效率增益；在相同预算下改善联合表现，才主张反馈分配的能力增益。材料：新增约十部留出作品（同一流水线）生成自然 R-S、S_T、F-D、L 历史；G 的结构不重调阈值即用。加入"请求证据"动作与模拟用户提供记录（真、假、不适用）的两步闭环。

## 8. 内部机制的进入条件

进入条件：自然历史中性辨别正确而施压后选择错误。目标是定位哪些内部计算改变了正确候选对最终输出的控制。因果干预须同时满足：错误施压下恢复正确判断；适用的正确证据出现时不重新锁死原错误。候选标签顺序须改变，供体与接收样本尽量用不同实体。若隔离正确而历史中性已错，研究历史对知识使用的影响，不统一命名为压力方向。机制结果是加强功能理论的路线，不是承认行为结果的前提。

## 9. 预注册的诚实规则

1. 统一方法足够时采用统一方法；不为证明闭环保留可解问题。
2. 简单模型预测足够好不算失败。
3. 零事件不算验证；前提不满足的假设记未检验。
4. 控制器的注记不抵消正文的错误否认；评价完整回答。
5. 共享采样不算独立证据；报告有效样本数。
6. 一般性来自共享结构成功预测新情形，不来自删除实验条件。
7. 不把当前协议的失败写成"任何方法都不可能"。

| 层级 | 最强主张 | 所需证据 |
|---|---|---|

| 可迁移解释 | 同一组状态变量与处理结构预测新关系中的错误类型与干预响应 | G 的预先给定预测 |
| 方法贡献 | 按诊断选择信息操作，在相同预算与可用证据下优于统一流程 | 第七批闭环评价 |
| 内部机制 | 某些内部计算对正确知识能否控制受压回答具有选择性因果作用 | 激活干预与正确证据更新对照 |

## 11. 摘要

本项目研究冻结语言模型在多轮冲突性反馈下的知识使用失配。前四批实验表明，在锚定事实上，受压错误无一表现为否认原有正确事实，而全部表现为保留相关事实、却采用不满足当前问题的答案；任何审慎式输入开头都把这类错误压到接近零，但同时增加某些真实关系的否认或错误先答的固守；在所测试的构造历史中，审慎也未恢复缺席的正确候选。基于这些发现，我们提出一个功能性框架，区分候选可用性、任务条件下的事实辨别，以及已有判断对最终回答的控制。核心假设是：相邻事实知识在不同处理条件下具有不同作用，而对当前任务限定的响应比回答自信更接近选择有效修复所需的信息。我们通过匹配的中性与受压识别、任务限定替换与措辞对照、候选比较和证据适用性实验独立测量这些状态，检验它们对干预收益的预测能力；随后在新的关系结构与可计算任务中检验共享解释，并构造依据诊断选择比较、重算、取证或明确未核实的闭环控制器。最终评价目标是在相同信息与计算预算下减少错误迎合与错误固守，同时保持事实完整性、有效证据更新与任务完成能力。
