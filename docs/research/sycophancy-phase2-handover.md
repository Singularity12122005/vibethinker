## 3. 科学主线（Phase 0 → 1 → 2）

**对象**：多轮对话中的"迁就"（sycophancy）——用户在后续轮次提出一个错误候选（例如把某译本错误归给某个译者），模型是否在下一轮把该候选署为"本版译者"。材料是 9 部公版译作（R-009 排除）的 62 段源历史（31 F-D + 31 S_T）等。

**第一阶段已确立**（见 `sycophancy-phase1-formulation-and-workflow.md` 及其附一至附四）：
- 模型生成下一轮回答时**直接读取自己上一轮的让步开场**，这改变它这一轮先写什么（首句让步率），进而改变人物署名与部分末行。
- **G1 时窗**：只在首个在线句界前遮断（T1）与全程遮断（O）对全文候选错署的效果相同（都 32/248）；句界后遮断（T2）≈ 原生（79 对 77）。即作用发生在开场写出之前。
- **G2 前缀四格**：固定前缀文字时，前缀**文字**效应 +0.250 [0.096, 0.400]，前缀期**计算**效应 −0.032。早期写出的内容及其形成的上下文，作用大于固定文字后的计算差异。
- **Z5**：操作移除的是对话诱发的候选错署，不是模型自身的版本错绑定。
- **镜像/Z3**：在无记录时，遮断会堵住一部分正确纠正（M0：正确更新 120/124→101/124，Δ₀ −0.153 [−0.342, +0.036]，损失集中在 R-003）。
- **NAT**：在模型自己写出的自然让步前序上复现（候选错署 41→12）。但自然让步首句**全部以 You 起句**。
- **E2**：遮断不增加版本选择性，在《父与子》上反而减少。

**第二阶段的问题**：那句开场里被读出的，是每写一词都要重读的线索，还是一个**低维、可携带、可定向修改的内部状态**？能否沿这条路径找到一个局部操作，让模型仍礼貌回应质疑、却不再把错误候选署为本版译者？

## 4. 第二阶段已经做了什么（P2-0 / P2-0b / P2-1a）

### 读数的确立（经过四次登记才稳住，教训见第 7 节）
- 主读数是**助手头末位置 t₀ 的单步让步开场读数 o_C**：首词元落在"让步集合 C"的对数几率（补集含全部未入 C 的质量）。按作品两折建表、折外验收：灵敏度 ≥ 0.80、特异度 ≥ 0.90。**不建"直接作答集合"**（它以内容开头、首词元长尾，按两类覆盖验收会失败，这是第一次登记的教训）。
- 与采样行为比较的量一律按**温度 0.7 匹配**（q_C^T = ΣC p^{1/0.7} / Σ p^{1/0.7}）；归因梯度用 T=1 的 o_C。对数几率尺度与概率尺度会给出相反的逐历史排序（曾导致一个"秩相关 −0.008"的假阴性，见第 7 节）；**效应量一律用温度匹配的概率尺度，差值与恢复量取"和之比"**（先分别对入选上下文求和再相除）。

### P2-0（零采样 + 归因，报告 `internal8_P0_v17.md`）
- 按归因（一次前向一次反向）选头，两折各独立完成选头/选层/选向/选秩。训练上下文按**全遮断效应 Δq ≥ 0.5** 入选（折 A 18 段 = {R-001,003,004,006,008}；折 B 31 段 = {R-002,005,007,010}）。
- 所选头组（13–21 个头，分布在第 33–46 层）在每层的**秩一**写入分量，在折外恢复"所选头完整补回"效应的 **98.7% / 95.3%**（相对全遮断入口概率差 98.3% / 98.9%）；**随机与正交余量近零**；两折方向逐层夹角 6°–30°。
- 分量分两组：**晚层组 L = {42,43,44,46}**（方向解码为 you/You/你，只对含该词形的开场起反应）；**中层组 S = {33,36,37,39,40}**（33 层对异词同义让步也响应）。两组在残差上近乎正交。**不要命名为"复制通路/语义通路"**；只写它们做了什么。

### P2-0b（零采样补充，报告 `internal8_P0b.md`）
- **晚层组是上一轮开场首词的复用通道**：读开场首词（42:21 注意力占跨度 98% You / 80%+ Yes / 74%+ Fair），提升同一词元作为下一轮首词，对 You 与 Yes 都成立，不随开场立场（接受纠正/维持原答）改变。换成不含该词形的异词同义让步句后，晚层移除**低于数值分辨**。
- **中层组含不随措辞消失的分量**：异词同义让步上移除仍降 You 概率 0.128；在文字逐词元相同时，中层移除使晚层写入下降 10%–26%（串联的直接证据）。但中层补回只恢复 0.049——必要性强于充分性。
- **词形边界**：原脚本所选头组对异词同义措辞只能补回 **13.1%**。头组是按词形选出来的，这条边界必须随结果一起写。
- **R-004**（遮断后仍让步的作品）剩余入口效应有一部分来自**编码当前压力消息时对开场的访问**（You 概率 0.619→0.432）；共同块无作用。

### P2-1a（主行为实验，1,488 条，报告 `internal8_P1a.md` + 盲核 `internal8_P1a_blind_review.md`）
六个新臂各 248 条（整组移除、整组秩一补回、所选头完整补回、配范数随机补回、仅移除中层、仅移除晚层），原生与全遮断两个参照复用实验七存档、共用抽样流。
- **主结局全文候选错署**：原生 77/248、全遮断 32/248；**整组移除 46/248**（移除效应 +0.125 [+0.029, +0.212]）；**整组秩一补回 88/248**（补回效应 +0.226 [+0.087, +0.359]）；完整补回同为 88；**配范数随机补回 31/248**（−0.004 [−0.036, +0.021]）。补回过登记半幅，移除未定。
- **必须一起写的不对称**：补回使当前关系答对下降 −0.121 [−0.195, −0.052]（已成立的**致害**）；移除使其上升但未定 −0.056 [−0.136, +0.016]（**保护未成立**）。所以只能写"对特定错误断言的双向因果作用"，**不能写"修复了关系绑定"**。
- **四格交互** −0.077 [−0.157, −0.009]：两组合并移除降幅超过单组之和，但（附十一）这主要是概率尺度的非线性，不需要专门的协同机制，也不定两组先后。

## 7. 已收回的过度主张与已踩过的坑（别重犯）

- 读数口径演化：两类覆盖验收失败（直接作答长尾）→ 改单侧让步对数几率；对数几率 vs 概率尺度给出相反逐历史排序，造出"秩相关 −0.008"的假阴性 → 一律温度匹配概率尺度、和之比。**定任何门槛前先做"可分辨性说明"**：用存档分布模拟该统计量在理想情况下的取值，理想值与零无明显距离的量不得作门。
- 把"阈值排除的 13 段"与"漏识别的 13 段"当成同一组（实际只重合 8 段）——核对 2×2 表。
- 把 recovery（概率差）误读成 fraction（比例），写出"六至九成"——结构化表里 recovery 是差、fraction 才是比例。
