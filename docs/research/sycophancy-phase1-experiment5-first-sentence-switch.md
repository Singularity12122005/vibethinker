## 1. 一页纸版本

**已知（来自实验四与 N1）。**

1. 译者题被用户施压后，"此刻若被迫作答写哪个名字"的读数 $d$（正值偏向用户的名字）在生成前几乎全部偏向用户的名字（保序率 0），不论用户对不对；作者题生成前保序率约 0.617，不在此列。
2. 无前缀时，模型第一句绝大多数是让步（F-D 147/156、S_T 240/248），之后群体曲线始终处于低位，末行保留原答案 2%–3%。
3. A1 前缀下第一句绝大多数是复述（243/248、152/156），S_T 保留正确原答案的比例从 0.19 升到第三句 0.690、第五句 0.710、终点 0.710：主要变化集中在前三句。
4. 作者题无前缀时首句也多为让步（232/240），群体保留率在第 1 句跌到 0.175，第 5 句回到 0.71；译者题让步后群体曲线始终处于低位。这与"知识强的题能回头"的解释一致，尚不构成证明。

**未知。** A1 的效果来自前缀文字的哪一部分：复述内容、"第一句不是让步"、还是整句指令的其余成分；现有数据里这三者绑在同一臂。

**做法。** 把模型第一句换成我们写好的四条句子之一（复述型、让步型、核实型、审慎型），后面让它自由写。同一批 130 段历史，每段每条各 4 条续写，与已有 base、A1 配对；看末行，也看每句之后 $d$ 怎么走。

**回答的问题。** (Q1) 这条脚本复述句能否非劣地替代 A1？(Q2) 在 P-R 达标的前提下，审慎句与核实句是否也达标？(Q3) 强制让步后，译者题与作者题的群体曲线是否回升？外加一个事前冻结、事后预测的检验：恢复形式模型给出的采纳风险分数，是否比 $(d_1,\alpha)$ 逻辑回归排序得更好。

**代价。** 新生成 1,560 条（P-A 若需补译者题再加 280，至多 1,840）；只读句末评分约 2–3 万次前向；零激活干预、零新作品。

## 2. 原因

### 2.1 证据链把问题逼到第一句

实验四：十种脚本开场放在生成前，都只能把 $d$ 拉回一部分（任何带内容的重新锚定削去证词增量约六成），生成前保序率最高 0.355；A1 的末行保留 0.710，差距在生成期。N1：生成期回复主要发生在复述首句后的前三句；无前缀时群体曲线始终处于低位；首句类型几乎由臂决定，与臂绑定，不能从观察数据拆出独立作用。N1 还表明开场对决策槽是差别压缩（模型自身倾向保留约 53%、证词约 32%），生成前读数解释不了末行。

因此下一刀是**由我们写第一句**：真正的因果操作，配对比较，作品差异在历史内抵消。

### 2.2 三个解释框架（本轮只检验具体文本是否足够，不裁定机制）

- **H1 避免让步即可**：预测审慎句、核实句、复述句都非劣于 A1。
- **H2 需要把问题重新摆到眼前**：预测只有复述句非劣于 A1（N1 两行分解：复述把自答行抬起约 21 logit）。
- **H3 A1 整体方案另有作用**：预测复述句明显低于 A1。本轮不能把"另有作用"定位到意图承诺；要定位，须另比较同一条复述句有无承诺句。
- **跨题型对照**：强制让步后，作者题群体曲线回升、译者题不回升，与知识强弱解释一致。

### 2.3 为什么价值高、为什么不是别的

直接决定控制旋钮的形状（文本规则拦截让步 / 注入一句复述 / 保留 A1 全句）；配对设计功效高；把动力学从描述变为事前冻结的预测。不做真假区分主题（10 部作品分不开真假与作品）；不先做激活干预（开关是否文本层面未定，§7）。

## 3. 概念与变量

- $d$：强制末行两行对数概率和之差，$d>0$ 偏向用户的名字。$d_t$：第 $t$ 个正文句末处的 $d$；$t=0$ 为开场后生成前。
- 保留率 keep：末行写回自答名字的续写比例（S_T 守住正确答案，F-D 坚持错误答案）；正确更新率 upd：F-D 末行写出真名的比例。历史内先平均续写，再历史等权。
- $\mathrm{ret}_d(O)$：实验四存档的生成前保序率。
- 首句类型：让步 / 复述 / 坚持 / 转向 / 其他，N1 的正则规则，不用模型。
- 恢复形式模型：$d_{t+1}-d_t=\kappa(\mu_i-d_t)+e$ 的线性化 $d_{t+1}-d_t=\beta_0+\beta_1\alpha_i+\beta_2 d_t+e$，$\kappa=-\beta_2$。只是预测模型的形式，不断言网络中存在恢复机制。
- 区分指数 $J(O)=\mathrm{keep}_{S_T}(O)+\mathrm{upd}_{F\text{-}D}(O)-1$：只并列描述。

## 4. 第 0 步：零前向，先做并冻结

### 4.1 三分量回归（接 N1，同口径）

**字串核对前置。** 逐历史核对 A′ 共同中性条件中的候选名与自答名字串是否与开场实验存档的 cand、own 原样字串逐字一致；不一致的历史剔除并列出，不为补齐新增前向。报告剔除后各单元历史数与作品数。

**模型。** 保留 N1 主模型结构（六开场 $a_O,b_O$、单元主效应 $c$、交互），把 $\alpha$ 拆为 $\alpha'$（不点名复核条件的候选边际）与 $\nu=\alpha-\alpha'$（点名条件相对不点名复核条件的增量，两条件整句措辞不同，不是纯名字出现效应）：

$$d_i(O)=a_O+c\,F_i+b_O\,\Pi_i+g'\,\alpha'_i+n\,\nu_i+b_F\,\Pi_iF_i+g'_F\,\alpha'_iF_i+n_F\,\nu_iF_i+e_{iO},\quad \Pi_i=d_i(O0)-\alpha_i.$$

作品簇野自助 2000 次（Rademacher 主、Webb 并报），按字串核对后实际保留的作品分簇。若有剔除，在相同保留样本上重拟合 N1 两分量主模型；全样本 0.53 仅作背景。

**可分离性。** 在两个单元内分别报告 $\alpha',\nu,\Pi$ 两两皮尔逊与斯皮尔曼相关及各自 VIF，并检查联合设计矩阵的秩。任一 VIF $>10$ 或皮尔逊 $|r|>0.9$，相应系数只报点值、不作判读；秩亏则记相应系数不可唯一估计，不以最小范数解作结果。主判读须两个单元的可分离性及联合矩阵满秩均通过。

**登记判读。** 主量 $(g'-n)+\tfrac12(g'_F-n_F)$：下界 $>0$ 记"不点名边际分量的系数高于点名增量分量"；含 0 记"未检出差别"；上界 $<0$ 记反向。另报 $g'+\tfrac12 g'_F$ 的区间是否含 1，与 N1 的 $g+\tfrac12g_F=0.53$ 并列；单元各自的有效系数描述。

### 4.2 恢复形式模型的拟合（在现有轨迹上）

**材料。** 实验三 B 的全部正文句末 $d_t$（译者题 base / A1 / status，作者题 S / S+A0 / S+A1 / C）。只用实测正文句末的相邻对 $(d_t,d_{t+1})$，$t\ge1$（**排除 $t=0\to1$**：第一句是设定区域的一步，性质不同；含 $t=0\to1$ 的版本作稳健性）。$T$ 只计正文句末，不含末行；行为终点不是实测 $d$，不进拟合。

**估计。** 每单元×臂一组：$d_{t+1}-d_t=\beta_0+\beta_1\alpha_i+\beta_2d_t+e$，每个转移等权，作品簇野自助 2000 次；历史随机截距版并报。$\alpha_i$ 为点名中性读数（作者题用其 C 臂）。

**可解释范围（事先规定）。** $\kappa=-\beta_2$：$0<\kappa\le1$ 记"单调靠近"；$1<\kappa<2$ 记"振荡靠近"；$\kappa\le0$ 记"无恢复形式"；$\kappa=2$ 记"无衰减振荡边界"；$\kappa>2$ 记"发散形式"。固定点 $\mu_i=(\beta_0+\beta_1\alpha_i)/\kappa$ 与斜率 $\beta_1/\kappa$ **只在 $\kappa$ 的区间下界 $>0.05$ 时报告**；否则记"固定点不可解释"，并仍报 $\beta_0,\beta_1,\beta_2$ 的区间，不删任何重抽结果。

**登记读数（描述性）。** 各单元×臂的 $\kappa$ 区间与范围归类；可报时 $\mu$（在 $\alpha$ 均值处）的符号与 $\beta_1/\kappa$ 的区间。事前预期：A1 臂与作者题 S 臂 $\kappa>0$，base 臂译者题 $\kappa$ 小或 $\beta_0$ 为正（向天花板漂移）。

**冻结。** 第 0 步的全部系数、残差方差、以及 §5.6 所需的预测步数在采样前提交；之后不改。

### 5.6 预测检验（恢复形式模型是否带来超出逻辑回归的排序力）

对象：S_T 的 P-R 新续写（主）；F-D 的 P-R、作者题的 P-C（并列）。自变量只取第一句之后的 $d_1$ 与该历史的 $\alpha_i$。

- **恢复形式模型（分单元机制预测）**：用第 0 步该单元 A1 臂（作者题用 S 臂）冻结的 $\beta$ 与残差方差，按递推式 $\hat d_{t+1}=\hat d_t+\beta_0+\beta_1\alpha_i+\beta_2\hat d_t$ 从 $d_1$ 前推 **固定步数 $h$**（$h$ 在第 0 步冻结：取可获得第一句读数的旧续写正文句数中位数向下取整后减 1，并以 0 为下限），高斯近似累加残差方差，输出"采纳风险分数" $\hat p=\Pr[\hat d_{1+h}+\epsilon>0]$。实际长度版只作事后辅助。
- **主比较器**：译者题在同单元 A1 臂、作者题在 X 的 S 臂旧续写上拟合的逻辑回归 $\Pr[\text{采纳}\mid d_1,\alpha_i]$（冻结）；**次比较器**：连续 $d_1$ 排序；基线：$d_0$ 排序。
- **合并版**：两译者单元 A1 合并、不用单元标签拟合同样两种预测器；系数、预测步数与残差方差均统一，不按真实单元切换，作为"不知真值时"的版本并列。
- **读数**：各预测器对实际末行采纳的 AUROC，作品簇区间；主登记量为恢复形式模型减主比较器的 AUROC 差：下界 $>0$ 记"用旧句末轨迹拟合的风险分数，优于用旧末行结局拟合的逻辑回归分数"；含 0 记"未检出"；上界 $<0$ 记"不如逻辑回归"。所有结果限定为"同一批历史的新续写"，不称对新作品的泛化。

### 5.7 事先写下的预期

P-R 在 S_T 的 keep 0.5–0.75，F-D 的 upd 0.6–0.75；P-C 译者题 ≤0.05、作者题 0.6–0.75；P-A 最不确定（0.3–0.7）；P-V 不确定，并可能出现目录相关措辞与名字同句出现的续写。预测检验的主登记量很可能含 0：三句定局意味着 $d_1$ 与 $\alpha$ 已承载多数信息。$J$ 不判读。

### 5.8 验收与不得

硬验收：上下文词元逐词元一致；$t=0$ 读数一致（$10^{-3}$）；采样设置一致并写明；解析器与首句规则不改；第 0 步参数与 $h$ 的提交号早于任何采样；作者题 S+A0 复用验收。不得：不事后增删或改写首句；不按结局挑选续写；不用模型做句子分类；不把 $J$ 写成判读；不把"非劣"或"等效"写成"相同"；不扩充作品；不做激活干预；不把 P-R 的结果写成一般"复述内容"的结论，也不把 H3 写成"意图承诺必要"。

### 5.9 预算

新生成 1,560（P-R、P-C、P-V 各 520）；译者题 A0 若缺再加 280，至多 1,840。句末评分约 2–3 万次只读前向。第 0 步零前向。

## 7. 之后（视结果）

若某条脚本首句非劣于 A1，再问"它是状态还是文字"：把该脚本上下文与 O0 上下文在生成前最后位置的残差差向量加到 base 臂生成过程里，看能否复现其末行效果。成功说明这项具体状态注入足以复现文本效果；失败只说明这项注入不足，不推出"必须依赖对首句文字的注意力"（位置、时机与注入方式都可能是原因）。需激活干预批准，另行登记。N1b（S−C 机制分解、P 区拆分、逐词元两行）优先级不变。


## 附一：六点复核裁定及执行边界（本轮用户已全部采纳）

1. 作者题的两个预测器均使用 X/S 训练；译者题均使用对应 A1。
2. 固定步数、共同方差下，恢复形式风险分数的排序等价于 d1 与 α 的线性组合，与逻辑回归同属线性排序形式。比较只支持两种拟合信息来源所产生分数的优劣，不将增量唯一归因于递推结构。
3. 非劣、超过容忍界限的劣势、尚未确定分别报告；具体脚本有效不推广为一般机制，排序改善不等于概率校准。
4. R4 的两个时点使用同一长度至少三句的续写集合与历史权重，结论限定在该子集。
5. 字串剔除仅检查本次实际候选、自答字串，不预设剔除作品；若剔除，在相同样本重拟合旧两分量模型。分单元检查可分离性，秩亏系数不作唯一点估计。
6. h = max(0, floor(median(T)) − 1)，T 不含末行。无 d1 的续写记不可评分，所有预测器使用同一评测集合。独立创新近似下，多步残差方差为 σ² Σ[j=0…h−1](1+β2)^(2j)；h=0 时直接使用 d1 排序，不计算零方差正态概率。合并版使用统一参数、h 和方差。
